# LS Overlay 2.1 deferred media and history backlog

M11.0 / LS Overlay 2.0 intentionally keeps the current static-media and
process-lifetime model. The following items are feature-frozen for 2.0 and must
not be pulled into release-candidate correction work:

- animated GIF and animated sticker playback;
- an animated-media on/off memory-saving mode;
- personal sales history, persistence, and statistics.

Any 2.1 design must retain the remote-only Discord architecture, bounded media
resources, canonical Discord message identity, human-reaction preservation, and
privacy/data-retention review before implementation.
