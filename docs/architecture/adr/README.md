# Gacha Overlay Architecture Decision Records

M8.0 Release Architecture Audit에서 동결한 핵심 설계 결정이다. 각 ADR은 구현 세부 설명서가 아니라, 후속 변경에서 유지해야 할 release invariant를 기록한다.

- ADR-001: Discord Local RPC Primary Source
- ADR-002: UIA Evidence-Only Policy
- ADR-003: No Server-Wide Subscription
- ADR-004: Sales Trust Model
- ADR-005: Async Generation/Revision Commit Policy
- ADR-006: Built-in + Sparse Override Catalog
- ADR-007: Surface vs Content Opacity
- ADR-008: Single Text Layout Renderer
- ADR-009: Public RPC/OAuth Distribution Decision
- ADR-010: Diagnostic Bundle Allowlist
