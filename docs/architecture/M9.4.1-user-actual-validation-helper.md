# M9.4.1 User Actual Validation Helper

M9.4.1 adds developer tooling only. It does not change Remote Chat, Legacy Chat,
Sales, Discord intents, pairing protocol, or DPAPI behavior.

## Start

From the repository root, run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\tools\dev\run-ls-m94-local.ps1"
```

This bypass applies only to this invocation. Do not permanently change the Windows
PowerShell execution policy.

The helper asks for:

- Target Discord Guild ID
- Optional tracked Host Discord user IDs
- Discord Bot Token through a non-echoing secure prompt

The Bot Token is never written to disk or included in command-line arguments. It is
placed in the helper environment only long enough to create the Backend process and is
removed before the WPF process starts.

## Session lifecycle

The helper creates one isolated temporary session containing:

- a Release Backend publish;
- a production-style win-x64 self-contained single-file WPF publish;
- the temporary Backend credential registry;
- safe Backend stdout/stderr logs.

The Backend binds to `http://127.0.0.1:5188`. The helper waits for `/healthz` and
Discord pairing-command readiness before starting the real WPF application.

Closing WPF does not remove Backend state. Enter `R` to relaunch WPF against the same
Backend credential registry and verify DPAPI credential recovery without pairing again.
Enter `Q` to quit the session.

On final quit or Ctrl+C, the helper stops only the Backend/WPF processes it created,
clears its environment, and removes its isolated temporary session directory. It does
not modify the public rc.1 artifact.

## Critical checklist

- Remote connection becomes Live in the WPF settings UI.
- The authorized channel catalog appears by channel name.
- Recent 20 and live text create/update/delete appear in the real HUD.
- Sticker, forwarded text, and forwarded image render in the real HUD.
- Remote/Legacy switching works and Sales remains on its existing path.
- WPF relaunch works without re-pairing while the helper remains open.
- Unpair/Forget returns Remote to PairingRequired.

M9.5 is not part of this helper.
