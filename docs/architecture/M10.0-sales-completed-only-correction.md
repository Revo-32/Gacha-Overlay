# M10.0 — 판매완료 전용 일반 판매 바

작성일: 2026-09-03

## 요청 및 원인

사용자가 판매중/판협중 이모지가 Discord 서버에서 삭제된 사실을 확인했습니다.
판매완료는 기존 운영 Backend에서 정상 처리되었고, 사용자 요청에 따라 클라이언트는
판매완료만 제공하도록 간소화했습니다. 이어진 요청으로 버튼을 Queue Detail에서
일반 판매 바로 옮겼습니다. 서버 설정·권한·배포 변경은 하지 않았습니다.

## 최종 동작

- 일반 판매 바 오른쪽에 판매완료 버튼 하나를 표시합니다.
- Queue Detail을 접거나 펼치는 것과 무관하게 사용할 수 있습니다.
- 본인 활성 판매글이 없으면 숨깁니다. 다른 현재 판매자의 글을 완료하지 않습니다.
- 본인 글이 여러 개면 대기열에서 가장 앞선 본인 글 하나를 대상으로 합니다.
  마우스를 올리면 대상 대기열 순번과 상품을 확인할 수 있습니다.
- HUD 잠금 중에는 비활성화하고 기존 전역 click-through를 유지합니다.
- RemotePrimary/Live 상태에서만 요청할 수 있습니다.
- 처리 중에는 중복 요청을 막고 일반 판매 바에 확인 중 문구를 표시합니다.
- 실패하면 일반 판매 바에 오류를 표시하고 판매글은 유지하며 재시도를 허용합니다.
- 공식 Discord 완료 read-back 후에만 활성 판매글을 제거합니다.
- 상세 목록에서는 모든 상태 버튼과 상태 문구를 제거했습니다.
  상품·작성 경과 시간·필요한 불명확 원문은 유지합니다.
- 판협중·판매중·봇 상태 지우기 UI command를 제거하고 클라이언트 UI 발신도 차단했습니다.
- Backend/Protocol의 기존 상태와 사람 Reaction 보호 정책은 호환성을 위해 유지합니다.
