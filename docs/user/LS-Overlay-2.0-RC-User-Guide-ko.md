# LS Overlay
## 게임을 보면서, 대화도 함께

2.0.0-rc.2 | 한국어 사용자 안내서

GTA Online 위에 Discord 채팅과 판매 순서를 보여주는 작은 도구입니다. 게임과 대화를 함께 확인하고, 내 판매글을 간편하게 완료 처리할 수 있습니다.

이 버전은 정식 2.0 출시 전 실제 사용 환경에서 확인하는 Release Candidate입니다. 중요한 사용 중 불편이나 오류가 있다면 마지막 장의 문의처로 알려주세요.

처음이라면 다음 장부터 순서대로 따라오세요.

- 시작과 로그인: 2~3쪽
- HUD와 채팅: 4~5쪽
- 판매와 세션: 6쪽
- 설정과 종료: 7쪽
- 문제 해결과 문의: 8~9쪽

LS Overlay는 독립 프로젝트입니다. Rockstar Games, Take-Two 또는 Discord의 공식 제품이나 승인된 제품을 뜻하지 않습니다.

# 1. 다운로드하고 실행하기

## 시작하기 전에

- Windows x64 PC와 인터넷 연결을 준비합니다.
- GTA V Enhanced / GTA Online과, LS Overlay를 사용할 Discord 서버에 접근 가능한 계정이 필요합니다.
- 로그인은 브라우저에서 진행합니다. 일반 채팅 표시에 Discord Desktop을 계속 켜둘 필요는 없습니다.

## 설치 순서

1. 배포 페이지에서 **LS-Overlay-2.0.0-rc.2-win-x64.zip**을 받습니다. **Source code**는 실행용 파일이 아닙니다.
2. ZIP을 우클릭해 **모두 압축 풀기**를 선택합니다. 원하는 새 폴더에 파일을 모두 풉니다.
3. 폴더 안의 **LSOverlay.exe**를 실행합니다. 별도의 .NET Runtime이나 개발 도구를 설치할 필요는 없습니다.

## 이전 버전을 쓰고 있었다면

기존 앱을 트레이 메뉴의 **종료**로 먼저 끕니다. 새 폴더에서 새 실행 파일을 실행하세요. 같은 Windows 계정에서는 기존 설정과 로그인을 계속 사용하도록 되어 있습니다. 기존 설정을 지우거나 폴더를 복사할 필요는 없습니다.

자동 시작을 사용한다면 새 버전을 한 번 실행한 뒤 설정을 확인하세요. 기존 바탕화면 바로가기는 새 실행 파일을 가리키도록 바꿔주세요. 자동 업데이트는 제공되지 않습니다.

## Windows 보안 경고가 보이면

이 시험판은 코드 서명되지 않아 평판 경고가 나타날 수 있습니다. 공식 배포 출처와 함께 제공된 파일의 SHA-256 확인을 먼저 권장합니다. 출처가 불확실하면 실행하지 말고 문의하세요. 보안 프로그램을 끄지 마세요.

# 2. Discord로 로그인하기

1. 처음 실행하면 언어를 **한국어**로 선택합니다. 이미 설정한 경우 설정의 **Discord** 화면을 엽니다.
2. **Discord로 로그인**을 누릅니다. 기본 브라우저에서 Discord 승인 화면이 열립니다.
3. 사용할 Discord 계정이 맞는지 확인하고 요청 내용을 읽은 뒤 승인합니다.
4. LS Overlay로 돌아옵니다. 연결이 완료될 때까지 잠시 기다립니다.
5. **허용된 메인 채팅 채널**에서 볼 채널을 선택하고 **선택 채널 사용**을 누릅니다. 초기 안내의 **다음**, **완료**를 따라갑니다.

## 다음 실행부터는

같은 Windows 계정에서는 저장된 로그인으로 자동 연결됩니다. 로그인을 직접 해제했거나 다시 승인이 필요한 경우에는 위 과정을 반복합니다.

## 계정과 승인 화면을 확인하세요

- LS Overlay를 사용할 Discord 서버에 들어가 있는 계정으로 승인하세요.
- 브라우저에서 다른 계정으로 로그인되어 있다면 계정부터 확인하세요.
- 인증 화면이나 주소에 포함된 개인 정보를 다른 사람에게 보내지 마세요.
- 승인 후 브라우저가 멈춘 것 같아도 먼저 앱의 연결 상태를 확인하세요.

## 로그인이 끝나지 않는다면

인터넷 연결과 서비스 상태를 확인하세요. 로그인 시간이 만료되었다면 앱에서 **로그인 취소** 후 새로 시작합니다. 계속 실패하면 발생 시간과 화면에 나온 짧은 오류 문구를 문의처로 보내주세요.

[서비스 상태 확인](https://status.revo32.cloud)

# 3. HUD 표시와 위치 조정

HUD는 게임 위에 보이는 채팅·판매 표시 영역입니다.

## 기본 단축키

- **F9**: HUD를 보이거나 숨깁니다.
- **F10**: HUD 잠금을 켜거나 풉니다.

단축키를 직접 바꾼 사용자는 설정의 **단축키** 화면에서 현재 키를 확인하세요.

## 게임을 할 때는 잠금

잠겨 있으면 HUD 위의 마우스 클릭과 스크롤이 게임으로 통과합니다. 채팅과 판매 목록은 계속 보이지만 버튼은 조작할 수 없습니다.

## 옮기거나 크기를 바꾸려면

1. GTA에서 메뉴를 열어 마우스를 사용할 수 있게 합니다.
2. **F10**으로 잠금을 풉니다.
3. HUD를 한 번 클릭한 뒤 상단 이동 영역을 드래그합니다. 미니멀 HUD에서는 위쪽의 작은 이동 바를 사용합니다.
4. 가장자리를 드래그해 크기를 조절합니다. 상단 톱니바퀴로 설정을 열 수 있습니다.
5. 위치가 정해지면 **F10**으로 다시 잠급니다.

## HUD가 보이지 않으면

Windows 우하단의 숨겨진 아이콘 표시를 열고 LS Overlay 아이콘을 우클릭하세요. **HUD 표시** 또는 **설정** 메뉴를 바로 열 수 있습니다.

GTA 화면에서만 표시하도록 설정했다면 게임을 앞에 두세요. 독점 전체 화면에서 가려지면 게임의 테두리 없는 창 모드를 확인하세요.

# 4. 채팅 읽기와 채널 전환

## 최근 채팅 보기

선택한 채널의 최근 메시지와 새 메시지가 표시됩니다. 이미지, 스티커, 이모지, 전달된 내용도 확인할 수 있습니다. Discord 역할 색상과 역할 아이콘, 메시지의 Reaction도 읽기 전용으로 보여줍니다. 같은 작성자가 연속으로 쓴 메시지는 한 묶음으로 정리됩니다. 원본이 삭제되었거나 불러올 수 없는 콘텐츠는 설명 문구로 표시될 수 있습니다.

## 이전 메시지를 읽으려면

1. **F10**으로 HUD 잠금을 풉니다.
2. 채팅 영역 위에서 위로 스크롤합니다. 표시 중인 최근 기록 범위에서 볼 수 있습니다.
3. 읽는 동안 새 메시지가 오면 **↓ N** 버튼이 나타납니다. N은 새 메시지 수입니다.
4. 버튼을 누르면 최신 메시지로 돌아갑니다.

전체 채팅 기록이 필요하면 Discord에서 확인하세요.

## 다른 채널로 바꾸기

설정의 **Discord**에서 **허용된 메인 채팅 채널**을 선택하고 **선택 채널 사용**을 누릅니다. 새 채널 준비가 끝나면 화면이 바뀝니다.

이전·다음 채널 단축키는 기본으로 지정되어 있지 않습니다. 필요하면 설정의 **단축키**에서 직접 지정하세요.

## Discord 창으로 이동하기

Windows의 **Alt+Tab**으로 실행 중인 Discord 창을 선택하세요. T 빠른 전환 기능과 해당 설정 항목은 제거되었습니다.

대화할 채널은 Discord에서 직접 선택하세요. 다시 게임으로 돌아갈 때도 Alt+Tab이나 게임 창 선택을 사용합니다.

# 5. 판매 목록과 세션 인원

## 판매 순서 확인

서버의 판매 채널에 올린 판매글을 바탕으로 현재 판매자와 대기 순서, 상품이 표시됩니다. 판매글 작성 자체는 Discord에서 합니다.

목록의 상품 이름이나 수량을 확인하세요. 자세한 내용은 화살표로 상세 목록을 펼쳐 볼 수 있습니다. 상세 목록의 Discord 이모지는 이미지로 표시되며, 불러오지 못하면 `:SELL_SP:`처럼 이름만 보여 ID 숫자가 노출되지 않습니다. 상세 목록은 정보 확인용이며 상태 변경 버튼은 없습니다.

## 내 판매가 끝났다면

1. **F10**으로 HUD 잠금을 풉니다.
2. 일반 판매 영역에서 내 글에 연결된 **판매완료** 버튼을 확인합니다. 상세 목록을 펼칠 필요는 없습니다.
3. 실제 판매가 끝났을 때 **판매완료**를 한 번 누릅니다.
4. 완료 상태가 확인되면 목록에서 해당 글이 사라집니다. 확인 중에는 잠시 기다려주세요.

다른 사람의 글에는 완료 버튼을 제공하지 않습니다. 연결이나 판매 상태가 아직 준비되지 않았다면 버튼을 사용할 수 없습니다. 사람이 Discord에서 직접 넣은 반응은 앱이 지우지 않습니다.

## 상세 목록과 잠금

상세 목록을 펼친 채로 잠그면 그대로 보입니다. 잠금 중에는 스크롤이나 버튼을 사용할 수 없고, 다시 풀면 조작할 수 있습니다. 판매 추적을 끄거나 목록이 비면 상세 목록은 접힙니다.

## GTA 세션 인원

설정에서 **GTA 세션 인원 표시**를 켜고 해당 **세션 호스트**를 선택합니다. 정보가 준비되면 **18 / 30**처럼 보이고, 가득 차면 **풀세션**으로 표시됩니다.

선택한 호스트의 정보가 없거나 연결이 준비 중이면 숫자가 나타나지 않을 수 있습니다. 내 게임 화면의 모든 세션을 직접 측정하는 기능은 아닙니다.

# 6. 내게 맞게 설정하기

## 설정 열기

HUD 잠금을 풀고 톱니바퀴를 누릅니다. HUD를 찾기 어렵다면 Windows 우하단 숨겨진 아이콘에서 LS Overlay를 우클릭하고 **설정**을 선택하세요.

## 먼저 바꿔볼 항목

- **일반**: 언어, 표시 방식, Windows 자동 시작을 확인합니다.
- **HUD**: 미니멀 HUD, 위치·표면 투명도, 세션 인원 표시를 조절합니다.
- **채팅**: 조선굴림체를 포함한 글꼴·크기와 테마, 작성자 간격을 고릅니다.
- **미디어**: 이미지 등 콘텐츠의 표시 설정을 확인합니다.
- **판매**: 판매 목록 표시와 알림 관련 옵션을 확인합니다.
- **인게임 타이머**: 일반·벙커·LSD 타이머의 시간과 시작 단축키, 완료 알림음을 관리합니다.
- **단축키**: F9/F10과 채널 전환 키를 확인합니다.

타이머를 시작하면 HUD에 남은 시간이 표시됩니다. 00:00에 도달하면 해당 타이머가 완료 표시되고, **타이머 완료 알림음**이 켜져 있을 때 알림음이 한 번 재생됩니다.

원하는 옵션을 하나씩 바꾸고 HUD에 반영된 모습을 확인하세요. 투명도를 너무 낮추면 밝은 게임 화면에서 글자를 읽기 어려울 수 있습니다.

## 창을 닫아도 계속 실행될 수 있어요

설정창을 닫거나 **트레이로 숨기기**를 누르는 것은 프로그램 완전 종료가 아닙니다. 앱은 우하단 알림 영역에서 계속 실행됩니다.

## 완전히 종료하기

1. Windows 우하단 숨겨진 아이콘 표시를 엽니다.
2. LS Overlay 아이콘을 우클릭합니다.
3. **종료**를 선택합니다.

새 버전으로 바꿀 때도 먼저 이 방법으로 기존 앱을 종료하세요.

# 7. 문제가 있을 때

## HUD가 보이지 않아요

F9를 누르고, 트레이 메뉴의 **HUD 표시**를 확인하세요. 게임에서만 표시 설정이라면 GTA를 앞에 둡니다. 게임의 테두리 없는 창 모드도 확인하세요.

## 채팅이 비어 있거나 연결이 안 돼요

인터넷과 [서비스 상태](https://status.revo32.cloud)를 먼저 확인하세요. 설정의 **Discord**에서 로그인 상태와 선택한 채널을 확인합니다. 연결이 복구되는 동안 잠시 기다려주세요.

## Discord 창은 어떻게 열어요?

Discord를 직접 실행하고 Alt+Tab으로 창을 선택하세요. 오버레이에는 T 전환 기능이나 해당 설정 항목이 없습니다.

## 판매완료 버튼이 안 보여요

내 계정의 판매글인지, 이미 완료된 글은 아닌지 확인하세요. HUD 잠금을 풀고 판매 연결이 준비될 때까지 기다립니다. 다른 사람의 글은 처리할 수 없습니다.

## 목록이 펼쳐져 있는데 클릭이 안 돼요

잠긴 HUD는 마우스 입력을 게임으로 통과시킵니다. F10으로 잠금을 풀고 HUD를 한 번 클릭한 뒤 다시 조작하세요.

## 상태 사이트도 열리지 않아요

잠시 후 다시 확인하세요. 계속 열리지 않으면 발생 시간과 앱의 오류 문구를 문의 이메일로 보내주세요. 보안 프로그램이나 서버 설정을 임의로 바꾸지 마세요.

# 8. 도움받기와 서비스 안내

## 문의할 때 알려주실 내용

- 사용 버전: **2.0.0-rc.2**
- 문제가 발생한 시간과 직전에 한 행동
- 예상했던 동작과 실제로 나타난 증상
- 가능하면 개인 정보를 가린 화면 한 장

인증 화면의 주소나 개인 대화가 그대로 보이는 이미지는 보내지 마세요.

## 지원 담당자가 진단 파일을 요청했다면

1. 설정의 **진단**에서 **진단 파일 만들기**를 누릅니다.
