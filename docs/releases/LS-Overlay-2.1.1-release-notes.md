# LS Overlay 2.1.1

재연결 후 복구와 움직이는 미디어의 성능·안정성을 개선한 핫픽스입니다.

## 주요 수정사항

- Remote 재연결 후 채팅 복구 경로를 개선했습니다. 지원되는 서버에서는 판매·세션 정보의 초기 동기화를 기다리지 않고 실시간 채팅 복구를 진행합니다.
- 판매·채팅 권한 확인 과정에서 동일한 권한 정보를 중복 요청하던 부분을 개선했습니다. 채널별 접근 권한 판정은 그대로 유지됩니다.
- 판매 목록의 초기 스냅샷과 이후 변경 내역을 연결하는 동기화 처리를 수정했습니다.
- GIF 및 움직이는 미디어의 프레임별 대용량 메모리 할당과 불필요한 복사를 줄였습니다.
- 디코더와 작업 버퍼를 재사용하고, 여러 움직이는 미디어가 표시될 때의 CPU 및 UI 경합을 개선했습니다.
- 애니메이션 디코딩을 UI 스레드 밖에서 처리하고 표시 우선순위를 낮춰 일반 채팅·입력에 양보하도록 했습니다.
- 애니메이션의 시간 흐름과 투명도·프레임 합성을 유지하면서 지난 표시 작업은 건너뛰고, 재생 종료 시 리소스 정리를 강화했습니다.

## 설치 및 업데이트

**LS-Overlay-2.1.1-win-x64.zip**을 새 폴더에 모두 압축 해제하고, 이전 앱을 트레이에서 종료한 뒤 **LSOverlay.exe**를 실행하세요. 별도 .NET 설치는 필요하지 않습니다.

기존 `%LOCALAPPDATA%\GachaOverlay` 폴더는 삭제하지 마세요. 호환되는 설정과 로그인 정보를 이어서 사용합니다. 기존 LS Overlay 2.1 빠른 시작·사용자 설명서를 그대로 제공합니다.

배포 파일은 첨부된 **LS-Overlay-2.1.1-SHA256.txt**와 대조할 수 있습니다. EXE는 ZIP 안에만 포함됩니다.
