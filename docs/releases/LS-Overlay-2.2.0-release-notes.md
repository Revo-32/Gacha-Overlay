# LS Overlay 2.2.0

클라이언트 메모리 사용량과 렌더링 효율을 개선한 성능 최적화 릴리즈입니다.

## 주요 변경사항

- 채팅 화면에서 사용하지 않는 표시 밀도의 UI 트리를 동시에 생성하지 않도록 개선했습니다.
- 텍스트 포맷과 레이아웃 처리에서 자원을 재사용해 불필요한 객체와 반복 작업을 줄였습니다.
- GIF 및 움직이는 미디어의 표시용 비트맵을 재사용해 프레임별 생성 비용을 줄였습니다.
- 설정 창 사용이나 오버레이 숨김/복귀 이후 움직이는 미디어가 다시 재생되도록 수명 관리를 보강했습니다.
- 중복 애니메이션 플레이어 등록을 방지하고 메시지 수정·삭제 시 미리보기와 관련 리소스 정리를 강화했습니다.
- GTA 컴패니언과 사업장 관리자에 잠금 해제 외곽선을 추가하고, 배경 투명도 0%에서도 창 가장자리로 크기를 조절할 수 있도록 수정했습니다.
- Discord 재연결 후 준비 완료 상태가 뒤늦은 연결 알림에 덮어써져 서비스 상태가 계속 비정상으로 표시될 수 있는 문제를 수정했습니다.
- 기존 테마, 글꼴, 미디어 품질, 애니메이션 시간 흐름과 기능은 유지됩니다.

## 성능 참고

실제 로그인 상태의 무미디어 비교에서 2.1.1 대비 Private Bytes가 약 20%, Working Set이 약 15% 감소한 표본을 확인했습니다.

실제 메모리 사용량은 표시 중인 메시지·미디어·설정과 시스템 환경에 따라 달라집니다. 모든 사용 환경에서 동일한 감소율을 보장하지 않습니다. 이 수치는 GIF 재생 A/B 비교 결과가 아니며, 실제 GIF 성능 A/B 비교는 검증 불가로 남겼습니다.

## 설치 및 업데이트

기존 LS Overlay를 트레이에서 완전히 종료한 뒤 **LS-Overlay-2.2.0-win-x64.zip**을 새 폴더에 모두 압축 해제하고 **LSOverlay.exe**를 실행하세요.

별도 .NET 설치는 필요하지 않습니다. 기존 `%LOCALAPPDATA%\GachaOverlay` 폴더는 삭제하지 마세요. 호환되는 설정과 로그인 정보를 이어서 사용합니다.

배포 파일은 첨부된 SHA-256 파일로 무결성을 확인할 수 있습니다. 빠른 시작 가이드와 상세 설명서는 2.2 버전 표기로 제공하며, 기능이 동일한 기존 UI 스크린샷을 사용합니다.
