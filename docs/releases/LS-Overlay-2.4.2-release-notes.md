# LS Overlay 2.4.2

GTA 컴패니언 주간 이벤트의 가독성을 개선한 클라이언트 UI 패치입니다.

## 변경 사항

- 4배·3배·2배 GTA$·RP 보너스를 각각 하나의 제목 아래 활동 목록으로 표시합니다.
- 속도 보너스는 GTA$·RP 보너스와 구분합니다.
- 같은 할인율의 차량·상품을 묶어 반복되는 할인 제목을 제거합니다.
- GTA+ 회원 전용 할인은 일반 할인과 구분하고, 기존 항목·조건·링크는 유지합니다.
- 좁은 HUD 폭에서도 목록이 줄바꿈되도록 표시합니다.

## 업데이트

**이번 변경은 클라이언트 수정이므로 새 ZIP을 받아야 적용됩니다.**

`LS-Overlay-2.4.2-win-x64.zip`을 새 폴더에 모두 압축 해제하고, 기존 앱을 트레이에서 완전히 종료한 뒤 **LSOverlay.exe**를 실행하세요. 별도 .NET 설치는 필요하지 않습니다.

기존 `%LOCALAPPDATA%\GachaOverlay` 폴더는 삭제하지 마세요. 설정·로그인 정보를 이어서 사용합니다.

빠른 시작·사용자 설명서는 기존 2.4 계열 PDF를 그대로 제공합니다. 문서의 이전 파일명 예시는 이번 2.4.2 ZIP과 체크섬 파일명으로 읽어 주세요.
