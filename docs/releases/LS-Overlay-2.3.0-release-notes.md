# LS Overlay 2.3.0

알림과 채팅 가독성, GTA 컴패니언, 판매 UI 및 GTA 클라이언트 감지 기능을 개선한 업데이트입니다.

## 주요 변경사항

- 중요한 이벤트를 한곳에서 확인하는 **알림센터**를 추가했습니다. 설정 왼쪽 종 버튼에서 열며, 채팅 영역을 사용하는 불투명 패널과 12pt 목록을 제공합니다.
- 나를 직접 멘션한 메시지와 내 메시지에 대한 답장을 구분하고, 다른 사용자를 멘션한 메시지는 불필요하게 강조하지 않습니다.
- 설정 → 채팅에서 **나를 멘션한 메시지 배경 강조**를 켜거나 끌 수 있습니다. 배경을 꺼도 알림 기록은 유지됩니다.
- 다음 판매 차례와 현재 판매 차례를 알림센터에서 확인할 수 있습니다. 개별 읽음·모두 읽음 처리를 지원합니다.
- 현재 판매 차례 안내를 상태 아이콘 옆에 자연스럽게 배치하고, 원문은 펼친 상세에서 표시합니다.
- 판매 상세에서 Discord 원문과 커스텀 이모지를 유지하고, 창 크기·잠금 상태 변경 후 로드된 이모지가 사라지던 문제를 수정했습니다.
- GTA 컴패니언의 한국어 용어와 문장 규칙을 개선했습니다. 숫자 보호 및 원문 대체 표시를 유지합니다.
- GTA 실행 감지 구조를 보강하고 컴패니언에 감지 상태를 표시합니다.
- 생산 타이머는 **로컬 GTA 실행 중 누적하며 스토리 모드도 포함**합니다. Alt+Tab을 GTA 종료로 처리하지 않습니다. 게임 화면에서만 표시하는 모드는 별도로 포커스를 사용합니다.

알림센터 전용 Windows 팝업이나 새 알림음은 추가하지 않았습니다. 기존 판매·타이머 알림음 설정은 유지합니다. 게임 메모리나 내부 재고를 읽지 않습니다.

## 설치 및 업데이트

**LS-Overlay-2.3.0-win-x64.zip**을 새 폴더에 모두 압축 해제하고, 기존 LS Overlay를 트레이에서 완전히 종료한 뒤 **LSOverlay.exe**를 실행하세요.

별도 .NET 설치는 필요하지 않습니다. 코드 서명과 자동 업데이트는 제공하지 않으므로 공식 배포처와 SHA-256을 확인하세요.

기존 `%LOCALAPPDATA%\GachaOverlay` 폴더는 삭제하지 마세요. 호환되는 설정과 로그인 정보를 유지합니다.
