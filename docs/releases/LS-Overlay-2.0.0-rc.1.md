# LS Overlay 2.0.0 RC1

버전: **2.0.0-rc.1** · Release Candidate · Pre-release

LS Overlay 2.0의 첫 번째 Release Candidate입니다. 실제 사용 환경에서 안정성과 사용성을 최종 확인하기 위한 사전 배포 버전이며, 정식 안정판은 아닙니다.

## 주요 변경사항

- LS Overlay 이름과 아이콘, 정돈된 HUD·설정 화면
- 브라우저에서 Discord로 로그인하고 최근 채팅·이미지·스티커·이모지 확인
- 원하는 채널로 전환하고, 이전 채팅을 읽다가 **↓ N**으로 최신 메시지로 복귀
- 일반 판매 영역에서 내 판매글을 바로 **판매완료** 처리
- 읽기 전용 상세 판매 목록과 선택한 호스트의 세션 인원 표시
- 다섯 가지 테마와 읽기 설정

## 처음 사용하는 경우

**LS-Overlay-2.0.0-rc.1-win-x64.zip**을 모두 압축 해제하고 **LSOverlay.exe**를 실행하세요. **Discord로 로그인**을 눌러 브라우저에서 승인한 뒤 앱으로 돌아옵니다. 채널을 선택하고 초기 안내를 완료하세요.

기존 사용자는 앱을 트레이에서 완전히 종료한 뒤 새 버전을 실행하세요. 같은 Windows 계정의 설정과 로그인 정보는 유지됩니다. 자동 시작을 사용하면 새 앱을 한 번 실행하고 설정을 확인하세요.

## 주요 단축키

- F9 (기본): HUD 표시/숨김
- F10 (기본): HUD 잠금/해제
- Discord 창 이동: Windows의 Alt+Tab 사용. T 빠른 전환 기능과 설정 항목은 제거됨
- 이전/다음 채널: 기본 미지정, 설정에서 지정

## 이번 RC에서 확인하고 싶은 부분

로그인과 재실행, 채팅·미디어 표시, 채널 전환, 판매완료, 잠금·스크롤, 연결 복구를 확인해주세요. 평소처럼 4~5시간 이상 사용한 결과도 도움이 됩니다. 진단 파일 생성 기능의 안정성도 함께 확인합니다.

## 알려진 사항

- Windows x64용 시험판이며 자동 업데이트와 코드 서명을 제공하지 않습니다.
- 보안 경고가 나타나면 출처와 함께 배포된 SHA-256을 확인하세요. 보안 프로그램을 끄지 마세요.
- 독점 전체 화면에서는 HUD가 가려질 수 있습니다. 테두리 없는 창 모드를 확인하세요.
- T는 Discord Desktop이 이미 실행 중일 때만 동작하며 채널을 자동 변경하지 않습니다.
- 원본을 불러올 수 없는 미디어는 설명 문구로 표시될 수 있습니다.
- 세션 정보가 준비되지 않으면 인원 표시가 나타나지 않을 수 있습니다.
