# LS Overlay 2.0.0

LS Overlay 2.0의 첫 정식 안정 버전입니다.

## 주요 기능

- 게임 위에서 Discord 채팅·이미지·이모지 확인
- Discord 역할 색상·역할 아이콘·Reaction 표시
- 같은 작성자의 연속 메시지 정리
- 판매 순서 확인과 내 판매글 **판매완료**
- GTA Online 세션 인원 표시
- 일반·벙커·LSD GTAO 타이머와 완료 알림음
- 조선굴림체를 포함한 글꼴·크기·테마·작성자 간격 설정
- 브라우저를 통한 Discord 로그인

## 기본 단축키

- **F9**: HUD 표시/숨김
- **F10**: HUD 잠금/해제

Discord 창은 Windows의 **Alt+Tab**으로 열어주세요. T 빠른 전환 기능은 제공하지 않습니다.

## 다운로드

Assets의 **LS-Overlay-2.0.0-win-x64.zip**을 받은 뒤 새 폴더에 모두 압축 해제하고 **LSOverlay.exe**를 실행하세요. GitHub가 자동 생성하는 **Source code**는 실행용이 아닙니다.

Windows x64용이며 별도 .NET 설치는 필요하지 않습니다. 기존 앱은 Windows 우하단 트레이에서 **종료**한 뒤 바꿔주세요. 자동 업데이트와 코드 서명은 제공하지 않습니다. Windows 보안 경고가 나오면 배포 출처와 함께 제공된 SHA-256을 먼저 확인하세요.
