# LS Overlay 2.0.0 RC2

RC1 피드백을 반영한 두 번째 Release Candidate입니다. 정식 안정판 전에 실제 사용 환경에서 안정성과 사용성을 확인하기 위한 사전 배포 버전입니다.

## 다운로드와 시작

1. Assets의 **LS-Overlay-2.0.0-rc.2-win-x64.zip**을 받습니다. GitHub가 자동 생성하는 **Source code**는 실행용이 아닙니다.
2. 새 폴더에 모두 압축 해제하고 **LSOverlay.exe**를 실행합니다.
3. **Discord로 로그인**을 누르고 브라우저에서 승인한 뒤 채널을 선택합니다.

Windows x64용이며 별도 .NET 설치는 필요하지 않습니다. 기존 앱은 Windows 우하단 트레이에서 **종료**한 뒤 바꿔주세요. 같은 Windows 계정의 설정과 로그인은 유지됩니다.

## 주요 변경

- Discord 역할 색상과 역할 아이콘 표시
- 메시지 Reaction 표시
- 같은 작성자의 연속 메시지 정리
- 일반·벙커·LSD GTAO 타이머와 완료 알림음
- 조선굴림체 추가
- 상세 판매 목록의 이모지·텍스트 표시 개선
- 작성자 간격·Reaction 크기 등 가독성 개선
- 봇 상태 문구를 **LS Overlay - 24/7 가동 중**으로 정리

기본 **F9**는 HUD 표시/숨김, **F10**은 잠금/해제입니다. Discord 창은 Windows의 **Alt+Tab**으로 열어주세요. T 빠른 전환 기능은 제공하지 않습니다.

## 사용 전 확인

자동 업데이트와 코드 서명은 제공하지 않습니다. Windows 보안 경고가 나오면 배포 출처와 **LS-Overlay-2.0.0-rc.2-SHA256.txt**를 먼저 확인하세요. 보안 프로그램을 끄지 마세요.
