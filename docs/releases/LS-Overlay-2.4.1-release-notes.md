# LS Overlay 2.4.1

주간 GTA 온라인 콘텐츠의 누락과 주간 도전 선택 문제를 수정한 핫픽스입니다.

## 주요 수정사항

- `2X`, `3X`, `4X GTA$ & RP` 등의 배수 제목 아래 여러 활동을 올바르게 연결하도록 주간 공지 분석을 개선했습니다.
- 할인율 아래 차량·부동산 목록과 `50% OFF:` 형식을 더 안정적으로 인식하도록 수정했습니다.
- 시승·경품 차량, 무기 밴 재고, 강탈 차량, 레이스, 타임 트라이얼 등 일부 주간 항목이 누락될 수 있던 문제를 수정했습니다.
- `Time Trial: ...` 같은 실제 콘텐츠 줄을 제목으로 잘못 처리하던 문제를 수정했습니다.
- 앞부분의 다른 보상이 아니라 실제 **금주의 도전** 항목을 선택하도록 수정했습니다.
- 주간 공지의 안전한 텍스트 필드를 기존 AI 번역 경로에 추가해 GTA 컴패니언의 한국어 표시 범위를 확대했습니다.
- 일부 주간 번역에서 보호된 활동명을 토큰 밖에 다시 써 중복 표시할 수 있던 응답을 검증하고 제한된 보정 경로로 처리하도록 수정했습니다.
- URL 또는 멘션이 포함된 항목은 AI로 전송하지 않으며 기존 번역 또는 원문 표시를 유지합니다.
- 한글 JSON 전송 크기를 줄여 검증된 주간 Snapshot이 기존 클라이언트 수신 한도를 넘던 문제를 수정했습니다. UI, Remote Protocol 스키마와 클라이언트 수신 한도는 변경하지 않았습니다.

## 설치 및 업데이트

**LS-Overlay-2.4.1-win-x64.zip**을 새 폴더에 모두 압축 해제하고, 기존 LS Overlay를 트레이에서 완전히 종료한 뒤 **LSOverlay.exe**를 실행하세요.

별도 .NET 설치는 필요하지 않습니다. 기존 `%LOCALAPPDATA%\GachaOverlay` 폴더는 삭제하지 마세요.

빠른 시작과 사용자 설명서는 승인된 2.4 계열 PDF를 그대로 제공합니다. 문서의 2.4.0 파일명 예시는 이번 릴리즈의 2.4.1 ZIP과 체크섬 파일명으로 읽어 주세요. 조작 방법은 동일합니다.
