## 기능 확인

- [ ] A. LSOverlay.exe가 별도 런타임 설치 없이 시작된다.
- [ ] B. 기존 사용자는 같은 Windows 계정에서 자동 로그인되고 설정이 유지된다.
- [ ] C. 새 사용자는 Discord로 로그인 → 브라우저 승인 → 앱 복귀 → 채널 선택을 완료한다. 기존 사용자에게 불필요한 연결 삭제를 요구하지 않는다.
- [ ] D. 최근 채팅, 새 메시지, 수정·삭제가 정상 표시된다. 위로 스크롤한 동안 새 채팅이 와도 읽는 위치가 유지되고 ↓ N으로 복귀한다.
- [ ] E. 허용된 채널을 전환하면 이전 채널의 내용이 섞이지 않는다. 지정한 이전/다음 키도 확인한다.
- [ ] F. 일반·전달 이미지, 스티커, 커스텀 이모지, 사용자 언급이 정상이다. 원본 unavailable은 설명 표시로 구분한다.
- [ ] G. F9/F10, 이동·크기 조절, 미니멀 HUD 톱니바퀴가 정상이다. 잠금 중 클릭과 휠이 게임으로 통과한다.
- [ ] H. 설정에 T 빠른 전환 항목이 없고 T가 Discord로 포커스를 바꾸지 않는다. Alt+Tab 이동, F10 잠금 해제 후 ESC 화면에서 HUD 클릭·스크롤이 정상인지 확인한다.
- [ ] I. 판매 순서·상품·자기 글 표시가 맞다.
- [ ] J. 실제 판매가 끝난 자신의 글에만 일반 판매 영역에서 판매완료한다. 확정 후 사라지고 다른 사람의 글에는 버튼이 없다. 사람 반응을 삭제하지 않는다.
- [ ] K. Queue Detail은 읽기 전용이다. 펼친 채 Lock/Unlock해도 보이며 해제 후 스크롤된다. 판매 OFF/빈 대기열/UltraCompact/새 앱 시작에서는 기존 자동 접힘을 유지한다.
- [ ] L. 선택한 세션 호스트만 표시된다. 인원 없음·풀세션도 구분한다.
- [ ] M. 테마·설정·트레이 메뉴·완전 종료가 정상이다. 자동 시작 사용자는 새 실행 경로도 확인한다.
- [ ] N. 일시적인 네트워크 단절 후 로그인 재승인 없이 복구되는지 확인한다. 채팅·판매·인원·알림이 중복되지 않는다. 다른 사용자의 서비스나 운영 Backend를 임의로 재시작하지 않는다.
- [ ] O. 지원용 진단 파일을 한 번 생성해 ZIP이 열리는지 확인한다. 실패하면 시각과 증상을 기록한다. 공개 업로드하지 않는다.
