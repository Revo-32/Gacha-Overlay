# LS Overlay 2.0.0 RC1

LS Overlay 2.0의 첫 번째 **Release Candidate (2.0.0-rc.1)** 입니다.
실제 사용 환경에서 안정성과 사용성을 최종 확인하기 위한 사전 배포 버전입니다. 정식 안정판이 아닙니다.

## 다운로드와 시작

1. 아래 Assets의 **LS-Overlay-2.0.0-rc.1-win-x64.zip**을 받습니다. **Source code**는 실행용이 아닙니다.
2. 새 폴더에 모두 압축 해제하고 **LSOverlay.exe**를 실행합니다.
3. **Discord로 로그인**을 누르고 브라우저에서 승인한 뒤 채널을 선택합니다.

Windows x64용이며 별도 .NET 설치가 필요 없습니다. 기존 앱은 우하단 트레이에서 **종료**한 뒤 바꿔주세요. 같은 Windows 계정의 설정과 로그인은 유지됩니다.

## 무엇을 할 수 있나요?

- 게임 위에서 Discord 최근 채팅, 이미지·이모지·스티커·전달 내용 확인
- 원하는 채널 전환, 스크롤과 **↓ N**으로 최신 채팅 복귀
- 판매 순서와 상품 확인, 내 판매글을 일반 판매 영역에서 **판매완료**
- 선택한 세션 인원 표시, 다섯 가지 테마, HUD 위치·읽기 설정

기본 **F9**는 HUD 표시/숨김, **F10**은 잠금/해제입니다. Discord 창 이동은 Windows의 **Alt+Tab**을 사용하세요. T 빠른 전환 기능과 설정 항목은 제거되었습니다. 채널 전환 단축키는 설정에서 지정하세요.

## 사용 전 확인

자동 업데이트와 코드 서명은 제공하지 않습니다. Windows 경고가 나오면 배포 출처와 **LS-Overlay-2.0.0-rc.1-SHA256.txt**를 먼저 확인하세요. 보안 프로그램을 끄지 마세요.
독점 전체 화면에서 HUD가 가려지면 테두리 없는 창 모드를 확인하세요.

ZIP 안에 한국어 안내서와 빠른 시작 README가 있습니다. 4~5시간 실사용, 로그인·재연결·판매완료·진단 파일 만들기 결과를 알려주시면 도움이 됩니다.
