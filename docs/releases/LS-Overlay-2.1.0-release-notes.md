# LS Overlay 2.1.0

LS Overlay 2.1.0은 Main HUD를 유지하면서 GTA 컴패니언과 사업장 관리자를 추가하고, 움직이는 Discord 미디어와 단축키 입력 경험을 개선한 정식 업데이트입니다.

## Highlights

- 오늘의 도전과 주간 정보를 보여 주는 **GTA 컴패니언**
- GTA Online 주요 생산·파견·쿨다운을 정리하는 **사업장 관리자**
- Animated GIF, 정적·움직이는 WebP, 지원 가능한 Discord 스티커와 Custom Emoji 재생
- 세 HUD를 함께 숨기는 F9와 공통 잠금/클릭 통과를 제어하는 F10
- 판매완료 확인 내역을 모아 보는 **내 히스토리**

## GTA Companion

- 오늘의 도전 3개를 선택하고 완료 상태를 직접 관리할 수 있습니다.
- 주간 도전과 주간 보너스·할인·이벤트 정보를 별도 플로팅 HUD에서 확인할 수 있습니다.
- 일일 정보는 매일 **15:00 KST**, 주간 정보는 매주 **목요일 18:00 KST**를 기준으로 전환됩니다.
- 주간 이벤트 내용을 끄고 도전 중심의 작은 화면으로 사용할 수 있습니다.
- Main HUD와 독립적으로 위치와 크기, 표시 단축키를 관리합니다.

## Business Manager

- 벙커 보급품 소모, 나이트클럽 금고수입, LSD 생산과 부스트, 세차장 용의도, 스페셜 패키지 창고, 항공 화물 직원 파견을 관리합니다.
- 구습·신습·카습·페습·코습을 각각 켜고 독립된 쿨다운을 확인할 수 있습니다.
- 페습과 코습의 하드 가능 구간은 쿨다운 흐름에서 자동으로 추적됩니다.
- 맨션 부스트는 한 번에 하나의 지원 대상에 적용되는 공유 상태로 관리됩니다.
- LSD 자체 생산 부스트의 생산량 한도와 24시간 만료를 함께 반영합니다.
- 5분 전·10분 전 미리 알림은 실제 완료 시각을 바꾸지 않습니다.
- 일반 12/24/48분 타이머와 완료 알림음도 사업장 관리자에 통합했습니다.

## Animated Media

- Chat과 전달된 메시지에서 지원되는 GIF/WebP 애니메이션을 재생합니다.
- Discord 래스터 스티커와 움직이는 Custom Emoji의 지원 경로를 확장했습니다.
- **움직이는 미디어 재생**을 끄면 애니메이션 대신 정적 미리보기 또는 안전한 대체 표시를 유지합니다.
- 제한을 벗어난 미디어와 손상된 프레임은 앱 전체 오류로 번지지 않도록 방어합니다.

## Chat / Sales UX Improvements

- 같은 작성자의 연속 메시지는 Author ID 기준으로 묶고, **작성자 간격**은 서로 다른 작성자 그룹 사이에만 적용합니다.
- Reaction과 역할 아이콘의 크기·위치 선택을 실제 HUD 가독성에 맞게 다듬었습니다.
- Sales Queue Detail의 Custom Emoji는 ID 문자열 대신 이미지 또는 이름 대체 표시를 사용합니다.
- 판매완료는 상세 목록을 펼치지 않아도 내 판매 행에서 바로 실행할 수 있습니다.
- 판매완료는 로컬에서 미리 확정하지 않고 서버의 신뢰 가능한 확인 결과가 돌아온 뒤 반영합니다.
- 판매 히스토리에서 제품별 최근 판매 시각을 확인하고 필요할 때 초기화할 수 있습니다.

## Hotkeys / HUD Controls

- 단축키 입력 칸을 누른 뒤 `K`, `F9`, `Ctrl + Shift + K`, `Alt + 1`처럼 키 또는 조합을 직접 입력합니다.
- 입력 중 ESC를 누르면 해당 매핑을 **미지정**으로 바꿉니다.
- 포커스를 잃으면 편집을 취소하고 이전 값을 유지합니다.
- 충돌하거나 중복된 단축키는 적용하지 않습니다.
- F9는 Main HUD, GTA 컴패니언, 사업장 관리자의 공통 표시 상태를 전환하되 개별 기능 설정은 보존합니다.
- F10 잠금 중에는 HUD가 마우스 입력을 가로채지 않습니다.

## Performance & Reliability

- Remote 재연결, 미디어 디코더 생성·해제, 단축키 재등록을 반복하는 경로를 강화했습니다.
- 숨겨진 사업장 관리자 HUD는 화면 갱신 비용을 줄이면서 도메인 타이머는 계속 진행합니다.
- 정상적인 타이머 갱신에서 불필요한 저장과 객체 재생성을 줄였습니다.
- 진단 번들은 민감한 값을 제한하고 사용자가 명시적으로 만들 때만 로컬에 저장합니다.

## Upgrade Notes from 2.0

- `%LOCALAPPDATA%\GachaOverlay` 경로와 호환 가능한 설정은 그대로 사용합니다. 업그레이드를 위해 이 폴더를 삭제하지 마세요.
- 기존 앱을 트레이에서 완전히 종료한 뒤 새 ZIP을 새 폴더에 압축 해제하고 `LSOverlay.exe`를 실행하세요.
- F9는 이제 활성화된 보조 HUD에도 공통 표시 상태를 적용합니다.
- 일반 타이머 설정과 화면은 사업장 관리자에 있습니다. 이전의 중복 타이머 화면은 제거되었습니다.
- GTA 컴패니언과 사업장 관리자는 기본적으로 꺼져 있으며 사용자가 설정에서 켭니다.
- 움직이는 미디어 재생은 기본적으로 켜져 있으며 미디어 설정에서 끌 수 있습니다.
- 2.1 런타임 UI는 한국어 중심으로 제공됩니다.

## Known Limitations

- Windows x64 전용이며 코드 서명과 자동 업데이트는 제공하지 않습니다.
- 독점 전체 화면에서는 HUD가 가려질 수 있으므로 테두리 없는 창 모드를 권장합니다.
- 사업장 관리자는 GTA 메모리나 재고를 직접 읽지 않습니다. 시작 시점은 사용자가 입력하고 일부 진행 여부는 확인 가능한 GTA Online 접속 상태를 사용합니다.
- LS Overlay를 닫은 동안의 GTA Online 플레이 시간은 추정하지 않습니다.
- Lottie 전용 스티커처럼 현재 디코더가 지원하지 않는 형식은 정적 또는 텍스트 대체 표시가 사용될 수 있습니다.
