## 주요 기능

- 선택한 Discord 메인 채널의 채팅을 HUD로 표시
- 이미지, 스티커, 전달 메시지의 Local RPC 가용 정보 처리
- 판매 채널 큐와 내장 상품 매핑
- SOLD 또는 닫힘 반응을 통한 판매 완료 및 Active Sales Queue 제외
- 5개 테마와 채팅 타이포그래피 설정
- F9 표시 전환 및 F10 잠금/클릭 통과 전환
- 온보딩, Discord 인증, 서버/메인 채널 설정
- 진단 ZIP 내보내기
- Windows 자동 시작 및 Discord 자동 실행 옵션

- 오류 처리와 진단 정보 수집 경로 강화
- 단일 파일 배포를 위한 버전, 리소스 및 패키지 구조 준비

## 지원 환경 및 빠른 시작

- Windows x64
- Discord 데스크톱 클라이언트
- 압축 해제 후 `Gacha Overlay.exe` 실행
- 첫 실행 온보딩에서 언어, Discord 인증, 대상 서버와 메인 채널을 설정
- 판매 큐를 사용할 경우 Discord 판매 채널 접근성 확인

실행 파일은 Windows x64 self-contained 단일 파일로 게시되어 별도 .NET 설치를 요구하지 않습니다.

## 알려진 제한 사항

### Platform limitation

- Local RPC에서 일부 스티커 메타데이터를 제공하지 않을 수 있습니다.
- 일부 전달 콘텐츠는 원본 형식을 완전히 판별할 수 없어 `[메시지]`처럼 일반화될 수 있습니다.
- 판매 반응 추적에는 Discord 채널 UI 접근성이 필요하며, 필수 UI가 없으면 판매 상태 갱신이 일시 중지될 수 있습니다.

### Current RC limitation

- 고정된 Production Guild와 판매 채널을 사용하며, 메인 채널 하나만 선택할 수 있습니다.
- 실행 파일 코드 서명은 구성되지 않았습니다.
- 자동 업데이트 기능은 없습니다.
- 종료 시점의 정량 Diagnostic Snapshot은 수집되지 않았습니다.

### Deferred public-release item

- 현재 Discord RPC/OAuth 구성은 제한된 테스트 배포용입니다. 더 넓은 공개 배포를 위한 OAuth 운영 정책은 추후 검토합니다.
