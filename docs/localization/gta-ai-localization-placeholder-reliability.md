# GTA AI Localization — 보호 토큰 진단 및 재시도 교정

## 범위와 기준

- 기준: `91c1dd281e291002c33997ef63b3cb70956f3b34`, `feat/gta-ai-localization`.
- main/Production 기준 `3e4a12434b6790752024c984dde71addaaf719cf`는 변경하지 않는다.
- 일반 영어 과보호 제거, 전체 Canonical 입력 보존, 불완전 입력 승격 차단은 유지한다.
- 이 문서는 **배포 전 로컬 검증** 기록이다. Staging 결과는 별도 운영 보고서로 남긴다.

## 확인한 원인

기존 Staging은 응답 본문을 보존하지 않았으므로 과거 두 응답의 실패 필드를 소급 확정할 수 없다.
동일 공개 캠페인 24필드를 기존 프롬프트로 통제 재현한 첫 응답에서는 오직 `field.003`이 실패했다.
예상 5개/관측 6개이며, 횟수 토큰 `[[L003_0001]]`이 중복되었다. 분류는 Duplicate와 CountMismatch다.
이 재현의 기존 일반 재시도는 통과했다. 이것을 과거 Staging 성공으로 간주하지 않는다.

중간 후보의 로컬 2회 응답은 같은 필드에서 보호된 용어 뒤에 단어를 반복해 RepeatedTerm으로 차단되었다.
이를 해결하기 위해 검증 규칙을 완화하지 않고 정확한 ValueFailure 사유도 재시도에 전달한다.

## 진단 및 재시도

- 내부 field.NNN, 예상/관측 수, Missing/Duplicate/Unknown/Mutated/CrossField/CountMismatch/Structural을 보고한다.
- 기존 숫자·단위·한국어 검증 실패도 안전한 열거형 사유로 구분한다.
- 각 토큰 목록은 최대 16개, 응답은 최대 64필드이며 생략 여부를 표시한다.
- 모델이 만든 외부 ID, 잘못된 토큰 본문, 원문/번역문, Discord 메타데이터는 진단에 복사하지 않는다.
- 실패 로그만 상세 진단을 포함한다. 캐시 로그는 프로세스 최초 적중 1회만 남긴다.
- 기존 입력 계약 + 이전 모델 응답 + 기계 진단으로 **전체 응답 재시도(A안)**를 사용한다.
- 실패 필드만 교정하도록 요청하되, 전체 JSON을 기존 엄격한 검증기로 다시 검사한다. 부분 병합은 만들지 않는다.
- 최대 호출은 최초 1회 + 재시도 1회다. HTTP 오류에 재시도 루프를 추가하지 않는다.
- 토큰은 기존 13자 `[[L000_0000]]` 형태를 유지한다. JSON 왕복 시 변경되지 않으며 이번 재현에서 문법 변경 증거는 없었다.
- 프롬프트 `gta-ko-3.3`, 재시도 `gta-repair-1`을 캐시 식별자에 반영한다.
- 보호 `gta-protect-2`, 용어집 `2026-09-08.1`, 한국어 표면 정책 `ko-surface-1`은 유지한다.

## 배포 후 판정

Staging에서 같은 실제 공고가 재시도까지 실패하면 추가 생성 없이 NO-GO로 중단한다.

## 사용자 계속 진행 승인 후 추가 교정

첫 교정 `adf44e585ab211250e26d4137968a35ffcac765d`의 Staging 배포
`75a9d754-c735-4dfe-bde1-50f03c368292`는 1회 생성으로 자동 검증을 통과했으나,

후속 변경:

- 현금/RP의 공통 배수가 두 보상 사이에 끼어들면 `ModifierScope`로 거절한다.
- 원문 보상 목록의 연구 속도가 누락되거나 현금/RP와 콜론 반대편으로 분리되어 별도 활동처럼 표시되면 거절한다.

- 재시도에 정확한 관계 오류와 연구 속도 배치 지침을 전달한다.
- 보호된 고유명의 한국어 별칭을 덧붙이지 않도록 프롬프트를 강화했다.
- 명시적인 소유자 창고 구문으로 수식된 배달 활동명은 미확정 고유명으로 보존한다. 일반 대문자 문장은 여전히 번역한다.
- 실제 원문의 `Duneloader`는 임의의 한국어 차량명을 생성하지 않도록 용어집의 `preserve_until_verified` 항목으로 추가했다.
