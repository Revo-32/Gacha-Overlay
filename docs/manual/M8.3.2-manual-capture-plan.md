## 개인정보 보호 및 마스킹

다음 항목은 최종 이미지에 남지 않도록 캡처 전 숨기거나 후처리로 완전 마스킹합니다.

- Client Secret
- OAuth access/refresh token
- 설명에 불필요한 Client ID
- 개인 Discord 계정 정보
- 무관한 Discord DM/메시지
- 비공개 서버 콘텐츠
- 불필요한 Windows 사용자명과 로컬 경로

마스킹 후 확대 검토를 수행하고 이미지 메타데이터에도 민감한 정보가 없는지 확인합니다. 실제 Secret 또는 Token 값을 예시 데이터로 재입력하지 않습니다.

## OAuth 설명 범위

- Discord Developer Application 생성
- Client ID 위치
- Client Secret 생성/찾기
- Redirect URI 설정
- 실제 필요한 경우의 controlled tester 설정
- Gacha Overlay에 값 입력
- Discord 인증
- Main Channel 선택
- 판매 호환 모드
- F9/F10 사용법
- 문제 해결

User Token 또는 Self-bot 사용 안내는 포함하지 않습니다.
