## 2. Design direction

### Cover

- 사용자가 제공한 `GachaOverlay_AppIcon_Source.png`를 수정 없이 주 시각 요소로 사용했다.
- Production `GachaOverlay-AppIcon.png`와 SHA-256 및 파일 내용이 정확히 일치함을 확인했다.
- Controlled Test Release, 제품 버전, 문서 버전, 실제 HUD 화면을 한 화면에서 식별할 수 있도록 재구성했다.

### Typography

- 제목: Wanted Sans Variable
- 본문: Pretendard Variable
- 일본어 fallback: Malgun Gothic
- 사용자에게 별도 글꼴 설치를 요구하지 않도록 PDF에 필요한 TrueType subset과 ToUnicode map을 포함했다.

### Color and layout

- 앱 아이콘과 현재 UI에서 파생한 Navy, Blue, Cyan, Yellow 팔레트를 사용했다.
- A4, 넓은 여백, 한 페이지 한 목표, 번호 마커, 경로 박스, 결과/보안/문제 해결 callout을 공통 규칙으로 적용했다.
- 화면 캡처는 가능한 크게 배치하고 UI를 가리는 장식은 사용하지 않았다.

## 4. Beginner-friendly improvements

- 처음 보는 용어를 목차 다음 페이지에서 설명했다.
- 포털과 앱의 실제 클릭 경로를 파란 경로 박스로 분리했다.
- 사용자가 직접 만드는 값과 앱이 자동으로 처리하는 값을 구분했다.
  - 사용자 준비: 개인 Discord Application, Client ID(App ID), Client Secret
  - 앱 자동 처리: OAuth access/refresh token 발급 및 보호
- 각 주요 단계에 `정상이라면`, `문제가 있다면`, `보안`, `중요` callout을 배치했다.
- 현재 Portal에서 Secret이 숨겨져 복사할 수 없는 새 Application 상태라면 Reset Secret으로 새 값을 발급하고 즉시 복사하도록 안내를 교정했다.
- `https://127.0.0.1`, `rpc`, `identify`, `messages.read`처럼 오타가 치명적인 값은 복사 가능한 검색 텍스트로 제공했다.
- F10 잠금 후 Queue Detail visibility 유지와 click-through/interactivity 분리를 별도 비교 페이지로 설명했다.
- Sticker/Forward metadata가 불완전할 때 `[스티커]` 또는 `[메시지]`가 보일 수 있는 이유를 단정적 오기 없이 설명했다.
- HUD가 화면에 보이지 않을 때 Windows 알림 영역의 숨겨진 아이콘에서 Gacha Overlay를 찾아 우클릭한 뒤 `HUD 표시`를 선택하는 복구 경로를 설치 문제 해결, HUD 문제 해결, Quick Reference에 추가했다. 실제 tray 구현과 한국어 리소스를 대조해 `설정`, `Discord 연결 설정`, `Discord 다시 연결`, `종료` 메뉴와 tray 아이콘 더블클릭 HUD 표시/숨김 동작도 정확히 안내했다.

## 7. Security and communication wording

- Client Secret과 OAuth token은 Windows current-user DPAPI 보호 대상으로 설명했다.
- User Token, Self-bot, browser DevTools token 사용을 금지했다.
- 인증 이후 실시간 Discord event의 주 경로가 PC 내부 Discord Desktop Local RPC/IPC Named Pipe라는 점을 명시했다.
- 별도 공개 웹 서버나 로컬 HTTP callback listener를 운영하지 않아 외부 노출 지점이 적다는 장점을 설명했다.
- 최초 OAuth token 교환, 필요한 token refresh, 미디어 다운로드에는 Discord 네트워크 통신이 사용될 수 있으므로 “최초 1회 이후 완전 오프라인” 또는 “절대 안전”이라고 과장하지 않았다.
- Diagnostic ZIP은 자동 업로드되지 않으며 전송 전 사용자가 직접 내용을 확인하도록 안내했다.
