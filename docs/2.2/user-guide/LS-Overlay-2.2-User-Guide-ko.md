# 1. LS Overlay 소개

LS Overlay는 GTA Online 화면 위에 Discord 기반 정보와 사용자가 관리하는 타이머를 표시하는 Windows x64 HUD입니다.

## 세 가지 HUD

- **Main HUD:** 선택한 Discord 채널의 Chat과 Sales 대기열을 표시합니다.
- **GTA 컴패니언:** 오늘의 도전, 주간 도전과 주간 이벤트 정보를 표시합니다.
- **사업장 관리자:** 생산, 파견, 쿨다운과 일반 타이머를 사용자가 시작하고 확인합니다.

세 HUD는 위치와 크기를 따로 기억합니다. F9는 활성화된 HUD들의 공통 표시 상태를, F10은 공통 잠금 상태를 다룹니다.

## 하지 않는 일

LS Overlay는 Rockstar의 공식 앱이 아니며 GTA 프로세스의 메모리나 재고를 직접 읽지 않습니다. Discord 정보를 Rockstar API에서 가져온다고 주장하지도 않습니다. 사업장 시작 시점처럼 자동으로 알 수 없는 정보는 사용자가 버튼으로 입력합니다.

# 2. 설치 및 첫 실행

## 지원 환경

Windows x64와 인터넷 연결이 필요합니다. GTA V Enhanced / GTA Online, 그리고 LS Overlay를 지원하는 Discord 서버에 접근 가능한 계정을 준비합니다.

## 설치

1. [GitHub Releases](https://github.com/Revo-32/Gacha-Overlay/releases)에서 `LS-Overlay-2.2.0-win-x64.zip`을 받습니다.
2. 배포된 `LS-Overlay-2.2.0-SHA256.txt`와 ZIP의 SHA-256을 비교합니다.
3. 새 폴더에 ZIP을 모두 압축 해제합니다.
4. `LSOverlay.exe`를 실행합니다.

LS Overlay는 별도 설치 프로그램이 없는 포터블 배포입니다. 하지만 설정과 상태는 실행 폴더가 아니라 `%LOCALAPPDATA%\GachaOverlay`에 저장될 수 있으므로 EXE를 지웠다고 사용자 데이터까지 자동 삭제되지는 않습니다.

## Windows 경고

코드 서명이 제공되지 않으므로 SmartScreen 경고가 나타날 수 있습니다. 공식 배포처, 파일명과 SHA-256을 확인한 파일만 실행하세요. Windows 보안 기능을 전역으로 끄지 마세요.

설치를 위해 소스 코드나 개발 도구를 받을 필요는 없습니다. ZIP 안의 실행 파일과 두 설명서, 라이선스 폴더를 함께 보관하세요.

# 2.1 2.0에서 업그레이드

1. Windows 우하단의 LS Overlay 트레이 아이콘을 우클릭해 기존 앱을 **종료**합니다.
2. 2.2 ZIP을 기존 파일과 섞지 않는 새 폴더에 압축 해제합니다.
3. 새 폴더의 `LSOverlay.exe`를 실행합니다.

## 그대로 유지되는 항목

- LocalAppData 호환 경로: `%LOCALAPPDATA%\GachaOverlay`
- 호환되는 화면·Chat·Sales 설정
- 기존 Remote 연결 자격 정보의 지원되는 업그레이드 경로

업그레이드를 위해 LocalAppData 폴더를 삭제하지 마세요. 삭제는 설정, 히스토리와 로컬 상태를 초기화해야 하는 경우에만 별도로 선택합니다.

## 달라진 위치와 동작

- F9는 활성화된 GTA 컴패니언과 사업장 관리자도 함께 숨깁니다.
- 일반 12/24/48분 타이머는 사업장 관리자에 있습니다.
- GTA 컴패니언과 사업장 관리자는 기본적으로 꺼져 있어 직접 켜야 합니다.
- 단축키는 칸을 누르고 바로 입력하며 캡처 중 ESC는 매핑 해제입니다.
- 움직이는 미디어 재생은 미디어 설정에서 끌 수 있습니다.

# 3. Discord 연결

LS Overlay 설정에서 **Discord로 로그인**을 누르면 시스템 기본 브라우저의 Discord OAuth 흐름이 시작됩니다.

1. 브라우저에 표시된 Discord 계정을 확인합니다.
2. 현재 승인 화면과 요청 범위를 읽습니다.
3. 승인 후 LS Overlay 완료 화면을 확인합니다.
4. 앱으로 돌아와 허용된 메인 채널을 고르고 **선택 채널 사용**을 누릅니다.

일반 사용자는 Bot Token, Discord 사용자 토큰, Client Secret, 서버 ID를 입력할 필요가 없습니다. Discord Desktop이 닫혀 있어도 브라우저 인증과 Remote 연결은 사용할 수 있습니다.

인증 탭이 열리지 않거나 완료되지 않으면 기본 브라우저, 인터넷 연결과 [서비스 상태](https://status.revo32.cloud)를 확인하세요. 계정이나 서버 권한이 맞지 않으면 앱이 사용할 수 있는 채널이 나타나지 않을 수 있습니다.

# 3.1 보안 및 개인정보

## 자격 정보

LS Overlay는 연결에 필요한 클라이언트 자격 정보를 현재 Windows 사용자 기준 보호 방식으로 저장합니다. 사용자의 Discord 토큰을 붙여 넣게 하거나 self-bot 방식으로 동작하지 않습니다.

## 통신과 진단

채팅, 판매와 세션·주간 정보는 인증된 서버 연결로 계속 받아옵니다. 최초 인증 후 통신이 모두 로컬로 바뀌는 것은 아닙니다. Discord Desktop 화면을 열어 두어야 정보를 읽을 수 있는 방식도 아닙니다.

진단 ZIP은 사용자가 설정에서 직접 요청할 때만 로컬에 생성되며 자동 업로드되지 않습니다. 민감한 값을 제한하도록 설계되어 있지만, 제3자에게 보내기 전에 내용과 전달 대상을 직접 확인하세요.

# 4. HUD 기본 조작

## F9 - 공통 표시

기본 F9는 Main HUD, GTA 컴패니언, 사업장 관리자의 공통 표시 상태를 전환합니다. GTA 컴패니언이나 사업장 관리자를 설정에서 개별적으로 꺼 둔 경우 F9가 그 기능을 강제로 켜지는 않습니다.

## F10 - 공통 잠금

- **잠금:** HUD가 마우스 입력을 받지 않는 클릭 통과 상태입니다. 게임 조작을 방해하지 않습니다.
- **잠금 해제:** 버튼, 스크롤, 위치 이동과 지원되는 크기 조절을 사용할 수 있습니다.

잠금 상태에서 Sales Queue Detail이 펼쳐져 있었다면 보이는 상태는 유지되지만 스크롤과 버튼은 입력을 받지 않습니다. 다시 잠금을 풀면 펼친 상태에서 상호작용이 복원됩니다.

## 트레이 메뉴

HUD를 찾을 수 없으면 Windows 우하단 숨겨진 아이콘에서 LS Overlay를 우클릭해 HUD 표시 또는 설정을 직접 열 수 있습니다.

# 4.1 독립 배치와 표시 상태

Main HUD, GTA 컴패니언, 사업장 관리자는 각각의 위치와 크기를 저장합니다.

1. F10으로 잠금을 풉니다.
2. 각 HUD의 드래그 영역을 잡아 원하는 모니터와 위치로 옮깁니다.
3. 지원되는 창은 가장자리에서 크기를 조절합니다.
4. F10으로 다시 잠급니다.

보조 HUD는 설정에서 개별 표시 단축키를 지정할 수 있습니다. 개별 단축키는 해당 HUD의 사용 여부를 바꾸지 않고 표시 상태만 전환합니다.

F9로 모두 숨겼다가 다시 표시하면 각 보조 HUD의 개별 표시 상태를 보존합니다. 예를 들어 GTA 컴패니언을 개별적으로 숨긴 뒤 F9를 눌렀다 돌아와도 GTA 컴패니언이 임의로 켜지지 않습니다.

독점 전체 화면에서 보이지 않으면 GTA의 테두리 없는 창 모드를 사용하세요. 여러 모니터에서는 각 HUD를 원하는 화면에 두고 위치가 복원되는지 확인합니다.

# 5. Main Chat 기본 사용

Main Chat은 설정에서 선택한 허용 채널의 최근 메시지와 새 메시지를 표시합니다.

- 작성자의 현재 표시 이름과 역할 색상·역할 아이콘을 가능한 범위에서 표시합니다.
- 언급은 이름을 확인할 수 있으면 `@이름` 형태로 표시합니다.
- 일반 메시지와 전달된 메시지의 텍스트·이미지를 구분해 안전하게 표시합니다.
- Reaction은 Emoji와 개수를 읽기 전용으로 표시합니다.
- 채널 전환 단축키를 지정하면 허용된 메인 채널 사이를 이동할 수 있습니다.

처음 연결하거나 채널을 바꿀 때 최근 메시지를 불러오는 동안 짧은 대기 상태가 보일 수 있습니다. 연결이 복구되면 같은 행이나 알림을 중복 생성하지 않고 최신 상태로 이어지는 것이 정상입니다.

Main Chat은 Discord에 메시지를 보내는 입력창이 아닙니다. HUD에서 보이는 Chat과 Reaction은 읽기 전용 표시입니다.

F10으로 잠금을 풀면 현재 불러온 목록을 스크롤할 수 있습니다. 오래된 메시지를 읽는 동안에는 새 메시지가 와도 읽던 위치를 유지하고, 맨 아래로 돌아오면 최신 메시지를 따라갑니다. Discord 전체 과거 기록을 무제한으로 보관하는 기능은 아닙니다.

아래쪽에 새 메시지 안내 버튼이 나타나면 눌러 최신 위치로 돌아갈 수 있습니다.

# 5.1 작성자 그룹과 가독성

연속된 메시지는 닉네임 문자열이 아니라 작성자 ID를 기준으로 그룹화됩니다. 같은 작성자가 연속으로 보낸 메시지 사이에는 자연스러운 작은 내부 간격을 사용하고, **작성자 간격**은 다른 작성자 그룹이 시작될 때만 적용합니다.

메시지가 삭제되어 그룹 경계가 달라지면 현재 메시지 목록을 기준으로 간격도 다시 계산됩니다.

## 주요 Chat 표시 설정

- 레이아웃 스타일과 시간 표시
- 글꼴과 글꼴 크기
- 줄 높이
- 작성자 간격: -2~48 DIP
- 닉네임·본문 외곽선과 두께
- 역할 아이콘 위치: 닉네임 왼쪽, 닉네임 바로 우측, 행 우측
- Reaction 크기
- 최대 줄 수와 표면 투명도

줄 높이와 작성자 간격은 서로 독립적입니다. 큰 작성자 간격을 사용해도 같은 사람이 연속으로 보낸 메시지가 각각 크게 벌어지지는 않습니다.

# 6. 움직이는 미디어

LS Overlay 2.2은 현재 디코더가 지원하는 범위에서 다음을 표시합니다.

- Animated GIF
- 정적 WebP와 Animated WebP
- Discord 래스터 스티커
- 움직이는 Custom Emoji
- 일반 첨부 이미지와 전달된 미디어

설정의 **움직이는 미디어 재생**을 끄면 애니메이션은 정지하고, 가능한 경우 정적 첫 프레임이나 대체 표시를 유지합니다. 이미지 표시, Custom Emoji, 스티커 설정은 각각의 기존 표시 정책도 따릅니다.

Lottie 전용 스티커처럼 현재 래스터 디코더가 애니메이션으로 처리하지 못하는 형식은 정적 또는 텍스트 대체 표시가 사용될 수 있습니다. 로딩에 실패한 Custom Emoji는 Snowflake ID를 노출하지 않고 이름 중심 대체 표시를 사용합니다.

APNG 스티커는 PNG 미디어 경로로 읽습니다. 디코더가 여러 프레임을 인식할 때만 재생하며, 모든 APNG의 애니메이션 재생을 보장하지는 않습니다.

미디어 캐시를 지운 뒤에는 필요한 이미지를 다시 불러옵니다. 채널을 전환할 때 이전 채널 행이나 애니메이션이 남지 않아야 합니다.

# 7. Sales 사용

Sales는 신뢰 가능한 서버 상태를 기준으로 판매 대기열과 상품 요약을 표시합니다.

## 대기열

- 서버에서 확인된 순서대로 판매 행을 표시합니다.
- 현재 판매자, 대기 인원, 상품과 다음 대기자 표시는 설정에 따라 달라질 수 있습니다.
- Queue Detail은 원문을 확인하는 읽기 전용 목록입니다.
- Custom Emoji가 포함된 원문은 이미지로 표시하고, 실패하면 `:이름:`처럼 표시해 숫자 ID가 보이지 않도록 합니다.

## 판매완료

자신의 판매 행에서는 상세 목록을 내리지 않고도 **판매완료**를 누를 수 있습니다. 이 동작은 로컬에서 즉시 판매를 끝낸 것으로 꾸미지 않습니다. 서버의 실제 반영과 다시 읽은 결과가 확인된 뒤 행이 사라지거나 상태가 갱신됩니다.

실제 사람이 직접 추가한 Reaction은 오버레이가 임의로 지우지 않습니다.

# 9. 사업장 관리자 - 먼저 알아둘 점

- **사용자 입력:** 보급품 채움, 인기도 최대, 직원 파견, 습격 종료처럼 실제 행동을 한 직후 버튼을 누릅니다.

# 9.1 WallClock과 OnlinePlaytime

타이머가 움직이는 기준이 서로 다릅니다.

| 기준 | 언제 진행되는가 | 앱을 껐다 켰을 때 |
|---|---|---|
| **WallClock** | 현실 시간의 경과를 계속 계산 | 저장된 완료 시각이 있으면 경과 시간을 계산해 복원 |
| **OnlinePlaytime** | LS Overlay가 명확한 GTA Online 접속 상태를 확인한 동안만 진행 | 앱이 꺼진 동안 GTA Online에서 플레이했을 시간은 추정하지 않음 |

예를 들어 같은 48분이라도 직원 파견은 앱이 꺼진 동안 시간이 흐릅니다. 생산 타이머는 접속을 확인하지 못한 구간을 빼고 실제로 확인된 플레이 시간만 쌓습니다.

OnlinePlaytime 타이머가 멈췄다면 버그라고 단정하기 전에 현재 세션/Presence가 GTA Online으로 확인되는지 보세요. 오프라인, 다른 게임, 연결 끊김 또는 알 수 없음에서는 진행을 멈추는 것이 의도된 동작입니다.

WallClock은 직원 파견과 쿨다운처럼 현실 시간이 지나면 완료되는 항목에 사용됩니다. 실제 분류는 각 항목 설명을 따릅니다.

# 9.2 벙커와 나이트클럽

## 벙커 - 보급품 소모

완전 업그레이드 제조 기준의 보급품 진행 모델을 사용합니다. 실제로 보급품을 채운 직후 **보급품 채움**을 눌러 시작하거나 다시 시작합니다. 진행은 OnlinePlaytime 기준입니다.

맨션 생산 부스트가 활성화된 벙커를 대상으로 선택되어 있으면 해당 시간 구간의 생산률에 현재 구현된 x3 배율이 적용됩니다. 부스트를 바꾸거나 앱을 다시 열어도 이미 계산된 진행을 임의로 되돌리지 않습니다.

설정의 **장비·직원 업그레이드 / 제조 중심** 조건이 실제 사업장과 일치하는지 확인하세요. 이 모델을 업그레이드하지 않은 사업장의 정확한 소모 시간으로 사용하지 마세요.

## 나이트클럽 - 금고수입

**인기도 최대**를 누르면 현재 설정한 금고 수입 목표 아래로 내려갈 때까지의 진행을 시작합니다. 기본 주기는 GTA Online 48분 단위이며, 직원 업그레이드 여부와 설정한 목표 금액이 계산에 반영됩니다.

표시 값은 GTA 내부 금고 잔액을 직접 읽은 값이 아니라, 사용자가 인기도를 최대화한 시점부터 계산한 목표 도달 카운트다운입니다.

# 9.3 LSD와 생산 부스트

LSD는 보급품 생산과 두 종류의 부스트를 구분합니다.

## 보급품 소모

업그레이드된 생산 기준으로 사용자가 보급품을 채운 시점에 시작합니다. 생산 진행은 OnlinePlaytime입니다.

## 자체 생산 부스트

- 생산률을 순간적으로 x2 적용합니다.
- 최대 80 생산 단위에 해당하는 허용량을 가집니다.
- 현실 시간 기준 최대 24시간 뒤 만료됩니다.
- 허용량이 먼저 끝나거나 24시간이 먼저 지나면 종료됩니다.
- 부스트가 유효한 동안 남은 허용량은 보급품을 다시 채워도 이어질 수 있습니다.

## 맨션 생산 부스트

맨션 부스트는 벙커와 LSD에 각각 독립적으로 두 개를 동시에 켜는 기능이 아니라 **하나의 공유 상태와 대상**을 가집니다. 현실 시간 24시간 동안 대상 사업장에 x3 배율이 적용됩니다. 설정의 맨션 보유 조건을 확인하고, 게임에서 선택한 사업장과 같은 쪽의 생산 부스트 버튼을 누르세요.

두 부스트가 같은 구간에 겹치면 현재 모델은 각 활성 배율을 함께 반영해 생산 진행을 계산합니다. 사용자는 복잡한 수식을 입력할 필요가 없습니다.

예를 들어 자체 부스트가 남은 상태에서 다시 보급해도 유효한 잔여량은 이어집니다. 오프라인에서는 생산이 멈추지만 24시간 만료 시각은 계속 다가옵니다.

# 9.6 미리 알림, 일반 타이머와 소리

## 미리 알림

사업장 타이머에 `사용 안 함`, `5분 전`, `10분 전`을 선택할 수 있습니다. 미리 알림은 실제 완료 시간을 앞당기지 않습니다.

예: 실제 완료가 18:00이고 10분 전을 선택하면 17:50에 미리 알림이 발생하지만, 진짜 완료 상태는 18:00에 전환됩니다.

## 일반 타이머

사업장 관리자 아래에서 12분, 24분, 48분 타이머를 바로 시작합니다. 선택적인 전역 단축키를 지정할 수 있으며 실제 시간 그대로 완료됩니다.

## 완료 알림

**타이머 완료 알림음**을 켜면 기존 알림 오디오 경로를 통해 완료된 슬롯마다 한 번만 소리를 냅니다. 매 화면 갱신마다 반복 재생하지 않으며 동시에 여러 완료가 생겨도 알림 폭주를 억제합니다.

# 10. 단축키 지정

1. 설정의 단축키 입력 칸을 클릭합니다.
2. 원하는 키 또는 조합을 누릅니다.
3. 필요한 섹션의 **단축키 적용**을 누릅니다.

## 지원 예

`F9`, `F10`, `K`, `Ctrl + F9`, `Ctrl + Shift + K`, `Alt + 1`

보조 키는 필수가 아닙니다. Ctrl·Shift·Alt는 함께 조합할 수 있습니다. 보조 키만 누른 상태는 완성된 단축키가 아닙니다.

## 편집 규칙

- 입력 대기 중 **ESC:** 해당 매핑을 `미지정`으로 설정
- 입력 칸이 포커스를 잃음: 편집 취소, 이전 값 유지
- 중복 또는 시스템 등록 충돌: 적용 거절, 이전 작동 값 복원
- **기본 단축키로 복원:** F9 표시/숨김, F10 잠금/해제 기본값 복원

F9와 F10을 새 키로 바꾸거나 미지정으로 설정할 수 있지만, HUD를 다시 조작할 방법을 잊지 않도록 트레이 메뉴 위치를 알아 두세요.

# 11. 연결과 앱 상태 변화

## Remote 재연결

네트워크가 잠시 끊기거나 서버가 다시 시작되면 HUD 앱은 열린 상태로 재연결을 시도합니다. 인증 정보가 유효하면 다시 페어링을 요구하지 않고 Chat, Sales, Presence와 GTA 컴패니언을 복구합니다.

재연결 중에는 일부 섹션이 준비 중으로 보일 수 있습니다. 복구 뒤 중복 Chat 행, Sales 행, 개인 알림이나 소리가 생기지 않아야 합니다.

## Discord Desktop 종료

인증이 끝난 뒤에는 Discord Desktop을 닫아도 Remote Chat, Sales와 서버 제공 상태를 사용할 수 있습니다. 브라우저나 모바일에서 발생한 지원 채널의 새 메시지도 서버 경로를 통해 반영됩니다.

## GTA Online 상태

선택한 호스트의 세션 정보만 HUD에 표시합니다. Presence가 오프라인·다른 게임·알 수 없음이면 OnlinePlaytime 타이머는 진행을 멈춥니다. 다시 명확한 GTA Online 상태가 확인되면 이어서 진행합니다.

# 11.1 진단 파일

설정의 **진단 및 복구**에서 `진단 파일 만들기`를 누르면 사용자가 지정한 위치에 ZIP을 저장합니다.

진단에는 문제 분석을 위한 제한된 상태·성능 정보와 정제된 로그가 포함될 수 있습니다.

- 메모리와 Private Working Set
- 프로세스 Handle과 Thread 수
- CPU 사용 정보
- 연결·기능 상태
- 정제된 제한 로그

Private Working Set은 이 프로세스가 전용으로 사용하는 실제 메모리입니다. Handle은 파일·창 같은 운영체제 자원, Thread는 작업 실행 흐름의 수입니다. CPU와 메모리의 순간값 하나보다 같은 사용 조건에서 계속 증가하는지와 실제 끊김 여부를 함께 알려 주세요.

진단 생성은 자동 업로드가 아닙니다. 파일을 만들기만 해서는 개발자나 서버로 전송되지 않습니다. 민감한 값을 제한하도록 설계되어 있지만 공유 전 내용을 확인하세요.

문제가 재현된 직후 진단을 만들고, 발생 시각과 사용 중이던 기능을 함께 적으면 분석에 도움이 됩니다. 무작정 LocalAppData를 삭제하기 전에 진단과 로그를 먼저 보존하세요.

# 12. 증상별 문제 해결

## HUD가 보이지 않음

F9, 트레이 메뉴의 HUD 표시, 해당 보조 HUD의 사용 설정을 차례로 확인합니다. 독점 전체 화면이면 테두리 없는 창 모드를 사용합니다.

## HUD를 클릭할 수 없음

F10으로 잠금을 해제합니다. 잠금은 마우스 클릭 통과가 정상입니다.

## 단축키가 적용되지 않음

입력 칸에서 키를 캡처한 뒤 적용 버튼을 눌렀는지 확인합니다. 중복·충돌 메시지가 있으면 다른 키를 고릅니다. ESC는 취소가 아니라 매핑 해제입니다.

## Discord가 연결되지 않음

인터넷, 기본 브라우저, 계정의 지원 서버 접근 권한과 서비스 상태를 확인하고 OAuth를 다시 시작합니다. 사용자 토큰이나 Bot Token을 만들지 마세요.

## GTA 컴패니언 정보가 비어 있음

Remote 연결과 기능 설정을 확인합니다. 새 주간 게시물 준비 중에는 Last-Good 정보 또는 섹션 내부 준비 중 안내가 나타날 수 있습니다.

## 사업장 타이머가 멈춤

OnlinePlaytime 항목인지, 현재 Presence가 GTA Online인지 확인합니다. 오프라인·알 수 없음에서는 추정하지 않습니다.

## GIF가 움직이지 않음

움직이는 미디어 재생, 미디어 형식 지원 여부와 캐시 상태를 확인합니다.

## Sales가 갱신되지 않음

판매 추적과 연결을 확인하고 필요할 때만 수동 재동기화를 한 번 실행합니다.

# 13. 로컬 데이터, 제거와 FAQ

## 앱 제거

실행 중인 앱을 트레이에서 종료한 뒤 압축을 푼 프로그램 폴더를 삭제합니다. 이것만으로 로컬 사용자 데이터가 자동 삭제되지는 않습니다.

## 선택적 데이터 초기화

호환 데이터 위치는 `%LOCALAPPDATA%\GachaOverlay`입니다. 이 폴더를 지우면 설정, 화면 위치, 히스토리와 로컬 상태가 초기화될 수 있으므로 백업과 목적을 확인한 뒤에만 수행하세요.

## 자주 묻는 질문

**Q. Discord 봇을 서버에 따로 설치해야 하나요?**
일반 사용자는 봇 설치나 Developer Portal 설정을 하지 않습니다. 운영 중인 지원 서버의 OAuth 연결을 사용합니다.

**Q. 사용자 토큰이 필요한가요?**
아니요. 브라우저 OAuth를 사용하며 사용자 토큰 붙여넣기를 요구하지 않습니다.

**Q. 앱을 꺼 둔 동안 타이머는 어떻게 되나요?**
WallClock은 저장된 완료 시각으로 경과를 계산할 수 있지만, OnlinePlaytime은 앱이 꺼진 동안의 GTA Online 시간을 추정하지 않습니다.

**Q. GIF가 메모리를 계속 늘리나요?**
디코더와 화면 리소스를 해제하고 제한을 벗어난 미디어를 방어하도록 설계·회귀 검증했습니다. 문제가 보이면 진단을 함께 제공하세요.

**Q. 여러 모니터에서 사용할 수 있나요?**
각 HUD를 원하는 화면으로 옮기고 위치를 저장할 수 있습니다. 해상도·배율 변경 뒤에는 위치를 다시 확인하세요.
