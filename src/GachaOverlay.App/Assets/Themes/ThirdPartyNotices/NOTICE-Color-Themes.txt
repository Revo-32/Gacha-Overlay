Gacha Overlay - Color Theme Attribution Audit
============================================================

Audit date: 2026-08-31

The Gacha Overlay theme system is an original semantic-token implementation.
It contains no copied theme source code, icons, screenshots, fonts, or binary
assets. The locally defined palettes were adapted from the approved M7.5.6
specification with the following projects used as naming and color references.

  Reference: GitHub Primer Primitives
  Source: https://github.com/primer/primitives
  License: MIT
  Copyright (c) 2018 GitHub Inc.

Nord
  Reference: Nord color palette
  Source: https://github.com/nordtheme/nord

Tokyo Night
  Reference: Tokyo Night VS Code theme

Monokai
  Reference: the classic built-in Monokai theme in Code - OSS
