# LS Overlay Core — M2 인증·통신 프로토타입

이 단계는 합성 데이터 기반 프로토타입입니다. 실제 Discord 승인/데이터, 네이티브 채팅·판매·세션 UI, 미디어는 아직 완료하지 않았습니다. Full을 대체하는 릴리즈가 아닙니다.

## 계약과 보안 경계

- 별도 `core_render_v1` 협상과 Core DTO/stream. 기존 Full envelope 및 16 KiB 한도는 유지합니다. 운영 API에는 Core endpoint를 등록하지 않았습니다.
- 기존 C# Chat/Sales/Session 의미를 서버에서 투영합니다. C++ Sales parser는 없습니다. 최종 줄바꿈·픽셀 배치는 클라이언트 책임입니다.
- 원문을 9,000-byte 조각으로 전송합니다. envelope는 16 KiB 이내, 논리 snapshot은 1 MiB 이내입니다. 순서·해시·세대·revision·20초 완료 한도를 확인하고 Ready 후 원자적으로 적용합니다. 초과 시 조용히 잘라내지 않고 명시 실패합니다.
- 동일 세대/revision은 중복 bootstrap 없이 재연결합니다. 불일치 시 전체 상태로 복구하며 새 Ready까지 마지막 정상 상태를 유지합니다. delta replay와 실제 Discord bridge는 후속 단계입니다.
- 기존 OAuth start/claim/cancel 계약을 WinHTTP로 구현했습니다. redirect/cookie/자동 통합인증은 끄고 HTTPS는 Windows 인증서 검증을 사용합니다. HTTP는 명시 loopback만 허용합니다.
- credential library는 별도 `%LOCALAPPDATA%\LSOverlayCore` 경로, origin별 파일, CurrentUser DPAPI를 사용합니다. 별도 테스트 경로에서 검증했으며 실제 로그인 UI에는 아직 연결하지 않았습니다. Full 로그인 파일은 읽거나 수정하지 않습니다.
- 합성 GUI 모드는 임시 인증만 사용하고 브라우저를 열거나 인증정보를 영구 저장하지 않습니다. 실제 Discord 승인으로 취급하지 않습니다.
- 통신은 worker에서 수행합니다. 제한된 재연결 backoff와 heartbeat/watchdog를 사용하며, heartbeat만으로 화면을 다시 그리지 않습니다. UI 계측 타이머는 명시 검증 모드에만 있습니다.

## 빌드와 로컬 검증

```powershell
& E:\CODEX\Worktrees\Gacha_Overlay-core\tools\core\build-native.ps1 -Stage m2
& E:\CODEX\Tools\dotnet8\dotnet.exe publish E:\CODEX\Worktrees\Gacha_Overlay-core\tools\core\LSOverlay.CoreFixtureHost\LSOverlay.CoreFixtureHost.csproj -c Release -o E:\CODEX\Worktrees\Gacha_Overlay-core\artifacts\core\m2\fixture-publish
& E:\CODEX\Worktrees\Gacha_Overlay-core\tools\core\verify-core-contracts.ps1 -IncludeGui
& E:\CODEX\Worktrees\Gacha_Overlay-core\tools\core\verify-native.ps1 -Stage m2 -PhaseSeconds 3 -NoHotkeys
```

네이티브 클라이언트는 .NET이 필요하지 않습니다. 위 .NET 도구는 서버 fixture를 빌드·실행하는 용도입니다. 자동 검증은 자체 창만 캡처하며 별도 Full 프로세스/설정은 변경하지 않습니다.

## M8 격리 개발 환경

`lsoverlay-core-dev` 프로젝트의 `fixture` 서비스만 사용합니다. 내부 네트워크, 공개 포트 없음, 운영 data mount 없음, 읽기 전용 filesystem, non-root, 128 MiB/0.5 CPU 제한입니다. 배포 위치는 `/srv/apps/lsoverlay-core-dev/m2/`이고 운영 Compose와 별개입니다. 실제 Discord용 자격증명은 설정되지 않았습니다.

터널을 유지할 콘솔:

```powershell
& E:\CODEX\Worktrees\Gacha_Overlay-core\tools\core\dev\connect-fixture.ps1
```

별도 콘솔에서 합성 창을 실행합니다:

```powershell
& E:\CODEX\Worktrees\Gacha_Overlay-core\artifacts\core\m2\native\Release\LSOverlayCore.exe --no-hotkeys --fixture-endpoint http://127.0.0.1:15188
```

`--fixture-verify <절대경로>`를 추가하면 연결 후 짧은 idle 측정과 자체 PNG 저장 후 종료합니다. 연결 shell 측정이며 실제 채팅 UI/미디어 KPI나 Full A/B 비교가 아닙니다. 종료하면 기존 Full의 운영 설정은 그대로입니다.

## 의존성

[yyjson 0.12.0](https://github.com/ibireme/yyjson/releases/tag/0.12.0)은 UTF-8 및 64-bit 정수 정확성, 작은 native C 의존성 때문에 선택했습니다. 자체 JSON parser나 무거운 framework는 추가하지 않았습니다. 소스 archive SHA-256을 CMake에 고정하고 wrapper에서 중복 키·깊이·byte 한도를 검사합니다. [MIT 고지](third-party/yyjson-LICENSE.txt)를 배포물에도 포함해야 합니다. dependency 소스/빌드는 Git에 포함하지 않습니다.
