LS Overlay Core 1.0.0

설치 및 실행
- Windows 10/11 x64용입니다.
- ZIP을 폴더에 모두 압축 해제하고 LSOverlayCore.exe를 실행하세요.
- fonts 폴더를 EXE와 함께 유지하세요. 별도 .NET, VC 런타임, Discord 데스크톱 앱, SSH 또는 PowerShell 설치/실행은 필요하지 않습니다.
- 처음 실행할 때 브라우저에서 Discord 로그인을 승인하세요. 기존 Core 개발판의 유효한 로그인은 재사용됩니다.
- 기존 LS Overlay 기본판(Full)의 설정과 로그인 파일을 가져오거나 변경하지 않습니다. F9/F10 충돌을 피하려면 기본판을 종료하세요.
- 이 배포물은 코드 서명되지 않았습니다. Windows가 알 수 없는 게시자 경고를 표시할 수 있습니다. 공식 GitHub 배포 출처와 SHA256SUMS를 확인하세요. 보안 기능을 끌 필요는 없습니다.

조작
- F9: HUD 표시 / 숨김
- F10: 잠금 / 잠금 해제
- 잠금 해제 후 우상단 톱니바퀴: 설정창
- Ctrl+Alt+왼쪽 / 오른쪽: 이전 / 다음 채팅방 (설정에서 변경 가능)
- 잠금 해제 후 상단 끌기 / 가장자리 끌기: 이동 / 크기 조절
- 트레이 아이콘 우클릭: 표시 / 잠금 / 종료
- 판매 완료 / 완료 취소: 본인 글에서만 제공하며, 확인창 없이 클릭 즉시 실제 Discord 상태를 변경합니다. 잠금 상태에서는 버튼이 숨겨집니다.

제공 기능
- 네이티브 채팅, 이미지/GIF/이모지, 판매 대기열 및 완료/취소, 세션 인원
- 메인, 1~6호실, 잡떡 중 접근 권한이 있는 채널 선택
- 글꼴/크기/외곽선/줄 간격/이모지 크기/투명도/단축키 설정
- 호스트: DE-SSANTA / -TheFirstStar-

기본판과의 차이
- 앞으로의 지원 대상은 LS Overlay Core입니다.
- GTA 컴패니언, 사업장 관리자, AI 번역, 알림센터 등 기본판의 모든 부가 기능을 이식한 제품은 아닙니다.
- Core는 운영 HTTPS 서버에 직접 연결하며 개발용 SSH 터널을 사용하지 않습니다.
- 인증이 끊기거나 권한이 사라지면 내용을 지우고 복구합니다. 복구 중 판매 조작을 자동 재시도하지 않습니다.
- 사용 중 로그인이 만료되면 브라우저 재승인이 필요할 수 있습니다. 승인을 취소했으면 앱을 다시 실행해 재시도하세요.

제거
- 트레이에서 종료한 뒤 압축 해제한 폴더를 삭제하면 됩니다.
- 개인 설정/암호화된 Core 로그인은 Windows 사용자별 로컬 앱 데이터에 별도 보관되며, 앱 폴더 삭제만으로 기본판이나 서버 데이터를 삭제하지 않습니다.
