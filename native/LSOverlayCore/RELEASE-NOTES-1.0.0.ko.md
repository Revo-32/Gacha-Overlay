# LS Overlay Core 1.0.0

LS Overlay Core의 첫 정식 릴리즈입니다. 앞으로의 개발·지원 기준은 Core이며, 기존 LS Overlay 기본판(Full)의 지원은 종료합니다. 기존 기본판 릴리즈와 파일은 보존합니다.

## 설치

`LS-Overlay-Core-1.0.0-win-x64.zip`을 다운로드하여 전부 압축 해제한 뒤 `LSOverlayCore.exe`를 실행하세요. `fonts` 폴더를 함께 유지해 주세요.

- Windows 10/11 x64용입니다. 별도 .NET, VC 런타임, Discord 데스크톱, SSH 터널이나 PowerShell 실행이 필요하지 않습니다.
- 최초 실행 시 브라우저에서 Discord 로그인을 승인합니다. 운영 서버에 HTTPS로 직접 연결합니다.
- **기존 기본판 사용자는 새 Core ZIP을 받아야 합니다.** 기존 설정·로그인을 자동으로 이전하거나 삭제하지 않습니다. 단축키 충돌을 피하려면 기존 기본판을 종료하세요.
- 코드 서명되지 않은 배포물입니다. Windows에서 알 수 없는 게시자 경고가 표시될 수 있습니다. 공식 배포 출처와 첨부된 ZIP SHA-256을 확인하세요. 보안 기능을 끌 필요는 없습니다.

## 포함된 기능

- 네이티브 채팅, 이미지·GIF·이모지, 판매 대기열과 본인 글의 판매 완료·취소, 세션 인원.
- 우상단 설정창: 글꼴·크기·외곽선·줄 간격·이모지 크기·투명도·단축키 조정.
- 메인·1~6호실·잡떡 중 접근 가능한 채널 선택 및 이전/다음 채널 단축키.
- F9 표시/숨김, F10 잠금/해제. 잠금 상태에서는 판매 조작 버튼과 채팅 스크롤바를 숨깁니다.
- 판매 안내의 세로 가운데 정렬과 판매 버튼 가운데 정렬. 판매 완료·취소는 확인창 없이 즉시 실제 Discord에 반영됩니다.
- Core 전용 운영 Backend와 격리 미디어 처리. 사용자별 권한 검사, 독립적인 채팅/판매 복구, 인증 만료·교체 시 연결 종료를 적용했습니다.

## 범위 및 검증

GTA 컴패니언·사업장 관리자·AI 번역·알림센터 등 기본판의 모든 부가 기능을 이식한 제품은 아닙니다.

전체 .NET 테스트 2,583개, 네이티브 테스트 7개, 합성 판매 UI 64개 assertion, 운영 이미지 Linux 통합 테스트 11개가 통과했습니다. 실제 운영 인증 연결·재연결·미디어 수신을 확인했고, 판매 완료·취소 및 최종 UI는 사용자 확인을 마쳤습니다. 장시간 실게임 성능이나 기본판 대비 A/B 수치를 보장하는 결과는 아닙니다.

배포 ZIP 안의 `build.json`에서 소스 커밋을, `SHA256SUMS.txt`에서 구성 파일 해시를 확인할 수 있습니다.
