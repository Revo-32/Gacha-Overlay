# Core M3 — 네이티브 채팅 텍스트 프로토타입

M3 전체 Chat parity 완료 문서가 아니다. 합성 canonical 데이터로 물리적 레이아웃·스크롤·네트워크 갱신을 구현한 내부 개발 단계다. 실제 Discord 연결과 이미지/커스텀 이모지/GIF 렌더링은 아직 검증하지 않았다. 미디어 대기 표시는 기능 완료나 허용된 품질 축소가 아니다.

## 구현 경계

서버는 기존 `ChatPresentationSynchronizer`, grouping, attention, Sales/Session domain 의미를 재사용한다. Core DTO의 `Attention`, `FallbackKind`, `Details`, `PresentationHash`는 의미/변경 식별 정보다. 줄바꿈·글자 위치·DPI는 서버가 결정하지 않는다. Full DTO와 production route를 변경하지 않는다.

네이티브 `ChatView`는 동일 snapshot의 JSON DOM을 연결 상태와 읽기 전용으로 공유한다. 보존 메시지의 UTF-16 레이아웃은 ID/presentation hash로 재사용하고, 스크롤 시 화면 밖 항목은 그리지 않는다. 서버 갱신 대기 슬롯과 Win32 wakeup 모두 최신 상태 하나로 합친다. 모든 revision을 UI에 재생하는 이벤트 로그는 아니다.

| 항목 | 이번 구현/검증 | 남은 확인 |
|---|---|---|
| 한국어/글꼴 | Full의 번들 글꼴 5개 선택, 작성자/본문 굵기, private font collection, 줄바꿈 | 사용자 실제 화면 및 Full 동일 설정 비교 |
| 작성자/역할 | 서버 grouping/색상, Unicode 역할 아이콘 3방향 위치 | 이미지 역할 아이콘은 M4 |
| 멘션/답글 | 직접 자기 멘션과 나에게 온 답글의 강조 구분, 배경 on/off, 원문 미확인 안내 | 실제 계정별 데이터 E2E |
| Unicode/링크 | OS color-font 렌더링, 원문/링크/현재 Full의 문자 단위 문법 유지, 스크립트 실행 없음 | ZWJ 포함 Full/Core 실제 glyph 비교 |
| 외곽선 | monochrome glyph geometry 캐시, round stroke, color glyph layer 제외, on/off | Full과 두께·DPI 시각적 비교; 개별 작성자/본문 설정 UI는 후속 |
| 스크롤 | wheel/키보드/스크롤바 드래그, 최신 추적, unread, retention, item/문자 위치 anchor | 사용자 실제 조작; 수정된 문장은 item 위치 fallback |
| 첨부/임베드/투표 | 비이미지 첨부·음성 길이·임베드 제목/요약·투표·구성요소의 안내 의미 보존 | 실제 복합 메시지 화면 비교 |
| 미디어/전달/반응 | opaque identity/metadata, 텍스트/Unicode 반응 수, 전달 텍스트, 미디어 대기 안내 | 커스텀 이모지·이미지·스티커·GIF 및 실제 실패 fallback은 M4 |
| 갱신/재연결 | 합성 continuous snapshots, bounded single-reader notification, 동일 상태 resume | real Discord bridge, 제품 OAuth 로그인 UI, 세션 만료 실통합 |

DirectWrite의 [색상 glyph 분리](https://learn.microsoft.com/en-us/windows/win32/api/dwrite_3/nf-dwrite_3-idwritefactory4-translatecolorglyphrun)로 monochrome geometry만 외곽선 처리한다. [Glyph outline API](https://learn.microsoft.com/en-us/windows/win32/api/dwrite/nf-dwrite-idwritefontface-getglyphrunoutline)의 경로를 레이아웃별로 캐시하고, fill은 기존 color-font DrawTextLayout을 유지한다. 모든 글꼴과 notice는 기존 번들 자산을 복사하며 OS 전체에 설치하지 않는다.

## 빌드/자동 검증

아래 도구는 현재 소스를 M3 artifact에 빌드한다. `-Stage m1`은 과거 소스를 복구하는 옵션이 아니므로 보존된 M1/M2 기준 바이너리를 덮어쓰지 않는다.

```powershell
& 'E:\CODEX\Tools\dotnet8\dotnet.exe' publish 'E:\CODEX\Worktrees\Gacha_Overlay-core\tools\core\LSOverlay.CoreFixtureHost\LSOverlay.CoreFixtureHost.csproj' -c Release --no-self-contained -o 'E:\CODEX\Worktrees\Gacha_Overlay-core\artifacts\core\m3\fixture-publish'
& 'E:\CODEX\Worktrees\Gacha_Overlay-core\tools\core\build-native.ps1' -Stage m3
& 'E:\CODEX\Worktrees\Gacha_Overlay-core\tools\core\verify-native-chat.ps1'
& 'E:\CODEX\Worktrees\Gacha_Overlay-core\tools\core\verify-core-contracts.ps1' -Stage m3 -IncludeGui
```

`verify-native-chat`는 별도 로컬 child 창에서 20개 메시지, 새 메시지/anchor, retention, 100회 스크롤, 40회 resize, 5개 글꼴/3개 아이콘 위치/외곽선/0% PNG와 8초 idle을 검사한다. 자신의 render buffer만 저장하며 Full 화면을 캡처하거나 사용자 프로세스를 종료하지 않는다. 이는 10분 mixed 안정성 시험 또는 성능 KPI 통과 판정이 아니다.

## 수동 화면 확인

위 export가 만든 합성 파일로 시작할 수 있다. 운영 로그인·설정과 무관하고 `--no-hotkeys`는 실행 중인 Full의 F9/F10을 보존한다.

```powershell
& 'E:\CODEX\Worktrees\Gacha_Overlay-core\artifacts\core\m3\native\Release\LSOverlayCore.exe' --no-hotkeys --chat-fixture 'E:\CODEX\Worktrees\Gacha_Overlay-core\artifacts\core\m3\chat-fixtures\chat20.json'
```

우클릭으로 글꼴/크기/멘션 배경/외곽선/역할 아이콘 위치를 바꾼다. 이 단계의 선택은 종료 후 저장하지 않는다. 잠금 해제에서 wheel·스크롤바·방향키/PageUp/PageDown/Home/End를 사용할 수 있다. 키보드 조작은 Core 창에 포커스가 있을 때만 적용된다. F9/F10 물리 입력 검증 때만 사용자가 Full을 종료하고 `--no-hotkeys`를 빼서 실행한다.

M8 격리 fixture 배포·SSH 접속은 `tools/core/dev/README.md`를 따른다. 운영 봇/앱/토큰을 복사하지 않는다. 별도 개발용 Discord 구성이 없다는 사용자 답변에 따라 실제 인증은 미실시로 남긴다.

## 현재 한계

개별 메시지의 미디어 decode/cache/authorized fetch, 실제 Discord source bridge, Sales/Session HUD, 설정 영속화/Full 설정 import, compact 등 세부 layout 옵션은 완료하지 않았다. `UpdateLayeredWindow` 전체 surface 업로드와 resize 시 재배치 비용을 실제 측정해 기록한다. 아직 Full보다 가볍거나 부드럽다고 단정하지 않는다. M4/M6의 원본 대형 GIF 비교 전에는 품질·성능 최종 GO를 내리지 않는다.
