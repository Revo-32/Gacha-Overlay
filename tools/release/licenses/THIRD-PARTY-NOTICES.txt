LS Overlay - Third-party notice index
=====================================

This LS Overlay 2.1.0 package bundles the .NET 8 Windows Desktop self-contained
runtime, fonts, palette references, and the SkiaSharp media decoder. Their
repository-preserved notices are staged under Runtime, Fonts, Themes, and Media.

Fonts
-----

- KIMM: source attribution and redistribution terms are recorded in
  Fonts/NOTICE-Fonts.txt.
- Cafe24 PRO Slim, Pretendard, and Wanted Sans: notices and the SIL Open Font
  License 1.1 are recorded under Fonts/.

Themes
------

- Palette reference attributions and the applicable MIT notice text are
  recorded in Themes/NOTICE-Color-Themes.txt.

Animated media
--------------

- SkiaSharp 3.119.1: the MIT license and attribution are recorded in
  Media/SkiaSharp.txt.

.NET runtime
------------

The applicable Microsoft .NET 8 runtime and Windows Desktop runtime license
texts, together with the .NET Runtime third-party notices, are recorded under
Runtime/. The source package identities and verification hashes are described
in Runtime/README.txt.
